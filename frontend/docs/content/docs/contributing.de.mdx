OpenFolia ist Open Source unter der AGPL-3.0. Wie Sie das Repository einrichten, welche Prüfungen
eine Änderung bestehen muss und wie Pull Requests geprüft werden, steht in `CONTRIBUTING.md` im
Wurzelverzeichnis des Repositorys; der Verhaltenskodex ist `CODE_OF_CONDUCT.md`, und wie Sie eine
Sicherheitslücke melden, steht in `SECURITY.md`.

## Diese Dokumentation

Die Website liegt im Repository, in `frontend/docs`, sodass eine Änderung an der API ihre
Dokumentation im selben Pull Request aktualisiert. Die handgeschriebenen Seiten sind MDX in
`frontend/docs/content/docs` (`page.mdx` auf Englisch, `page.de.mdx` auf Deutsch). Die
Referenzseiten werden bei jedem Build erzeugt und nie von Hand bearbeitet.
