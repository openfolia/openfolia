Ein neues Modul wird in Ihrer Überarbeitung angelegt. Legen Sie zuerst eine Überarbeitung im
Entwurf an oder wählen Sie eine: siehe
[Eine Überarbeitung anlegen](/de/guide/change-sets/start-a-revision).

1. Wählen Sie **Inhalte** in der Seitenleiste.
2. Wählen Sie oben rechts **Neues Modul**.
3. Geben Sie einen **Titel** ein. Darunter sehen Sie die ID, die das Modul bekommt: **Gespeichert
   als sensoren-reinigen**.
4. Prüfen Sie die **Ausgangssprache**: die Sprache, in der Sie schreiben.
5. Wählen Sie den **Modultyp**, etwa **Procedure** oder **Safety**.
6. Wählen Sie die **Zielgruppe**: wer das Modul lesen darf. Ohne Zielgruppe zählt es als die am
   stärksten eingeschränkte Stufe; die Auswahl zeigt **Nicht gesetzt: zählt als Internal**. Siehe
   [Zielgruppen](/de/guide/manuals/audiences).
7. Füllen Sie die Felder aus, die Ihr Projekt ergänzt, etwa **Region**, und fügen Sie nach Bedarf
   **Schlagwörter** hinzu: Drücken Sie nach jedem <kbd>Eingabe</kbd> oder tippen Sie ein Komma.
8. Wählen Sie **Anlegen und öffnen**.

![Der Dialog Neues Modul mit einem Titel, der daraus gebildeten ID und dem Modultyp](/images/guide/de/new-module.webp)

Das Modul öffnet sich im Editor, leer und für Sie gesperrt.

## Mit einer Kopie beginnen

Um mit dem Text eines anderen Moduls zu beginnen, kreuzen Sie **Mit einer Kopie eines anderen
Moduls beginnen** an und wählen Sie unter **Zu kopierendes Modul** das Modul. Das neue Modul bekommt dessen
Blöcke; das Original bleibt, wie es ist.

## Wenn der Titel schon vergeben ist

Die ID entsteht aus dem Titel. Gibt es schon ein Modul mit dieser ID, sagt der Dialog das. Wählen
Sie einen anderen Titel.
