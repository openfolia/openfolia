Manche Rollen dürfen Inhalte nicht direkt bearbeiten, aber Änderungen vorschlagen, etwa jemand im
Service, dem ein falscher Wert auffällt. Ein Vorschlag ist eine eigene Überarbeitung mit einem
Modul darin. Jemand prüft sie wie jede Überarbeitung.

## Eine Änderung an einem Modul vorschlagen

1. Öffnen Sie das Modul unter **Inhalte**. Es öffnet sich schreibgeschützt: **Schreibgeschützt:
   Schlagen Sie eine Änderung vor, um es zu bearbeiten**.
2. Wählen Sie oben rechts **Änderung vorschlagen**. Eine Überarbeitung mit dem Namen des Moduls
   wird angelegt, und das Modul öffnet sich darin zum Bearbeiten.
3. Ändern Sie den Text.
4. Füllen Sie unter **Ihr Vorschlag** **Was haben Sie geändert?** aus: was Sie geändert haben und
   warum. Die Prüfenden lesen das zuerst.
5. Wählen Sie **Zur Prüfung einreichen**.

![Ein Vorschlag: das Modul zum Bearbeiten geöffnet, Ihr Vorschlag mit seiner Notiz und Zur Prüfung einreichen](/images/guide/de/module-suggest.webp)

Das Modul ist wieder schreibgeschützt: **Schreibgeschützt: Ihr Vorschlag ist in Prüfung**. Ist er
freigegeben, wartet er auf die Veröffentlichung mit dem nächsten Zusammenführen.

## Ein neues Modul vorschlagen

Wählen Sie unter **Inhalte** **Neues Modul vorschlagen**. Es wird in einer eigenen Überarbeitung
mit seinem Namen vorgeschlagen und im Editor geöffnet. Schreiben Sie es und reichen Sie es wie oben
ein.

## Wer vorschlagen kann

Ihre Rolle entscheidet, ob Sie bearbeiten oder vorschlagen: siehe
[Rollen](/de/guide/reference/roles). Wer bearbeiten darf, kann **Änderung vorschlagen** ebenfalls
nutzen, als Abkürzung: Es legt eine Überarbeitung für dieses Modul an und wählt sie.
