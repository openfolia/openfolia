Die Stilprüfung bittet ein Sprachmodell um Änderungen am Wortlaut eines Moduls: Text, Titel,
Alternativtexte und die Legenden von Positionsnummern. Nichts ändert sich, bis Sie einen Vorschlag
übernehmen.

Die Stilprüfung ist aus, bis Ihr Admin sie einrichtet. Ohne sie hat der Reiter Vorschläge kein
**Stil prüfen**; die [Schreibprüfung](/de/guide/checks/writing) ist trotzdem da. Für Admins: siehe
`CCMS_STYLE_REVIEW_URL` in der [Einstellungsreferenz](/de/reference/settings).

## Ein Modul prüfen

1. Öffnen Sie das Modul in Ihrer Überarbeitung im Entwurf.
2. Wählen Sie **Vorschläge** in der Seitenleiste.
3. Wählen Sie **Stil prüfen**. Das Modell liest das Modul in der gespeicherten Fassung.

![Der Reiter Vorschläge: Stilprüfung mit zwei Vorschlägen, jeder mit Übernehmen, Anzeigen und Verwerfen](/images/guide/de/module-style-review.webp)

Jeder Vorschlag nennt, worum es geht (**Text**, **Titel**, **Alternativtext**,
**Legende einer Positionsnummer**, …), sagt warum und zeigt den aktuellen Text durchgestrichen neben dem
vorgeschlagenen.

## Mit einem Vorschlag arbeiten

- **Übernehmen** setzt den vorgeschlagenen Text ein und speichert ihn. Die Meldung bietet
  **Rückgängig** an.
- **Anzeigen** führt Sie zu der Stelle im Modul, bei der Legende einer Positionsnummer zu ihrer
  Positionsnummer im Bild.
- **Verwerfen** nimmt den Vorschlag aus der Liste.

Jeder Vorschlag ist auch im Text markiert, gestrichelt unterstrichen. Zeigen Sie darauf oder setzen
Sie den Cursor hinein und drücken Sie **Alt+Enter**, für seine Karte mit **Übernehmen** und
**Verwerfen**.

**Erneut prüfen** holt neue Vorschläge, etwa nachdem Sie das Modul geändert haben.

## Wenn sich der Text inzwischen geändert hat

Ein Vorschlag passt zum Text, wie er geprüft wurde. Haben Sie diesen Text seitdem geändert, lehnt
**Übernehmen** ihn ab: **Der Text hat sich seit der Prüfung geändert, daher wurde der Vorschlag
nicht übernommen. Prüfen Sie erneut.** Der Vorschlag sagt das dann anstelle von Übernehmen.
Verwerfen Sie ihn, oder wählen Sie **Erneut prüfen**.
