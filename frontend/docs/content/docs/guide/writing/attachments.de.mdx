Ein Anhang bietet Lesern eine Datei zum Herunterladen an, etwa eine Beispielkonfiguration oder ein
Datenblatt. Dateien der meisten Typen lassen sich anhängen.

## Eine Datei anhängen

1. Setzen Sie die Einfügemarke dorthin, wo der Anhang stehen soll.
2. Tippen Sie <kbd>/</kbd>, dann `anh`, und wählen Sie **Anhang**. Er steht auch im Menü
   **Einfügen**.
3. Wählen Sie in **Datei anhängen** eine Datei aus der Liste. Tippen Sie in **Dateien nach Name oder
   Modul suchen**, um eine zu finden. Oder wählen Sie **Hochladen**, um eine Datei von Ihrem Rechner
   hinzuzufügen: Sie wird in Ihre Überarbeitung hochgeladen und gewählt.
4. Tippen Sie unter **Name** die Worte, die Leser statt des Dateinamens sehen, etwa
   „Beispielkonfiguration“. Der Name ist erforderlich.
5. Tippen Sie eine **Beschreibung**, wenn sie hilft.
6. Wählen Sie **Einfügen**.

![Der Dialog Datei anhängen: eine hochgeladene JSON-Datei, ihr Name und ihre Beschreibung](/images/guide/de/writing-attach-dialog.webp)

Der Block zeigt den Namen, den Dateinamen, Typ und Größe und die Beschreibung:

![Ein Anhang mit Herunterladen und Bearbeiten](/images/guide/de/writing-attachment-block.webp)

**Herunterladen** speichert die Datei. **Bearbeiten** oder ein Doppelklick öffnet **Anhang
bearbeiten**, um Datei, Namen oder Beschreibung zu ändern.

## Welche Dateien angenommen werden

Das Hochladen lehnt eine zu große Datei ab, in der Grundeinstellung größer als 50 MB. Es lehnt auch
Dateien ab, die Code ausführen oder als Webseite öffnen könnten, etwa HTML-Seiten, SVG-Bilder,
Programme und Skripte: **Dateien dieses Typs können Code ausführen oder als Seite öffnen und werden
hier abgelehnt.** Eine Datei, deren Inhalt nicht zu ihrer Endung passt, wird ebenfalls abgelehnt. Ihre
Administration kann die Größengrenze und die angenommenen Typen ändern.

## Sicheres Herunterladen

Eine angehängte Datei wird immer heruntergeladen, nie im Browser geöffnet, im Editor wie im Portal.
Sie wird unter dem Dateinamen gespeichert, den der Block ihr gibt.

## Wenn eine Datei fehlt

- **Datei nicht gefunden oder für Sie nicht sichtbar**: Die Datei ist weg oder in Inhalten, die Sie
  nicht lesen dürfen. Wählen Sie **Bearbeiten** und hängen Sie sie erneut an.
- **Die Datei konnte nicht heruntergeladen werden.**: Wählen Sie **Erneut versuchen** in der Meldung.

Die [Medienbibliothek](/de/guide/media/attachments) listet alle angehängten Dateien.
