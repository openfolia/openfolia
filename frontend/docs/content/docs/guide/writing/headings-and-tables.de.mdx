Überschriften gliedern ein Modul in Abschnitte. Eine **Überschrift 2** steht in einer **Überschrift
1**, eine **Überschrift 3** in einer **Überschrift 2**. Listen und Tabellen fassen den Text
dazwischen.

## Eine Überschrift hinzufügen

1. Setzen Sie die Einfügemarke in eine Textzeile.
2. Öffnen Sie in der Werkzeugleiste das Menü **Absatzformat**. Es nennt das Format an der
   Einfügemarke, etwa **Text**.
3. Wählen Sie **Überschrift 1**, **Überschrift 2** oder **Überschrift 3**.

Oder beginnen Sie eine leere Zeile, tippen Sie <kbd>/</kbd> und wählen Sie eine Überschrift. Eine
Ebene, die an der Einfügemarke nicht stehen kann, ist ausgegraut und sagt warum, etwa **Braucht
davor eine Überschrift derselben Ebene, unter die sie rückt.**

![Das Menü Absatzformat in einer Überschrift 2, Eine Ebene tiefer ausgegraut, Eine Ebene höher wählbar](/images/guide/de/writing-heading-levels.webp)

Die **Gliederung** links listet die Überschriften als H1, H2 und H3.

## Eine Überschrift eine Ebene höher oder tiefer setzen

1. Setzen Sie die Einfügemarke in die Überschrift.
2. Drücken Sie <kbd>Tab</kbd> für **Eine Ebene tiefer** oder <kbd>Umschalt</kbd> <kbd>Tab</kbd> für
   **Eine Ebene höher**. Beides steht auch am Ende des Menüs **Absatzformat**.

Der Text unter der Überschrift und ihre Unterüberschriften wandern mit. Überschriften gehen höchstens
drei Ebenen tief. In einer Liste, einer Tabelle, einem Variantenblock oder einem Sicherheitshinweis
kann keine Überschrift stehen.

## Eine Liste anlegen

1. Wählen Sie in der Werkzeugleiste **Aufzählung** oder **Nummerierte Liste**, oder tippen Sie
   <kbd>/</kbd> und wählen Sie eine davon.
2. Mit <kbd>Eingabe</kbd> kommt der nächste Eintrag. <kbd>Eingabe</kbd> in einem leeren letzten
   Eintrag beendet die Liste.
3. Mit <kbd>Tab</kbd> rückt ein Eintrag unter den davor, mit <kbd>Umschalt</kbd> <kbd>Tab</kbd> wieder
   zurück.

## Eine Tabelle anlegen

1. Tippen Sie <kbd>/</kbd>, dann `tab`, und wählen Sie **Tabelle**. Eine neue Tabelle hat zwei
   Zeilen und zwei Spalten; die erste Zeile ist die Kopfzeile.
2. Tippen Sie in die Zellen. <kbd>Tab</kbd> springt in die nächste Zelle, <kbd>Umschalt</kbd>
   <kbd>Tab</kbd> in die vorige. <kbd>Tab</kbd> in der letzten Zelle fügt eine
   Zeile an.
3. Für Zeilen und Spalten wählen Sie in der Werkzeugleiste **Tabellenaktionen**. Die Schaltfläche ist
   da, solange die Einfügemarke in einer Tabelle steht.

![Das Menü Tabellenaktionen: Kopfzeile, Zeilen, Spalten, Verbinden und Ausrichtung](/images/guide/de/writing-table-menu.webp)

In **Tabellenaktionen**:

- **Kopfzeile** macht die erste Zeile zur Kopfzeile oder wieder zur normalen Zeile.
- **Zeile oberhalb einfügen**, **Zeile unterhalb einfügen**, **Spalte davor einfügen** und **Spalte
  danach einfügen** fügen neben der Zelle an der Einfügemarke eine Zeile oder Spalte ein.
- **Zeile löschen**, **Spalte löschen** und **Tabelle löschen** entfernen sie.

Eine Tabelle kann keine Tabelle enthalten.

## Zellen verbinden

1. Setzen Sie die Einfügemarke in die erste Zelle.
2. Wählen Sie in **Tabellenaktionen** **Mit nächster Zelle verbinden** oder **Mit Zelle darunter
   verbinden**.

**Zelle teilen** trennt eine verbundene Zelle wieder. Solange eine Tabelle verbundene Zellen hat,
können Sie keine Zeilen und Spalten hinzufügen oder entfernen: Das Menü sagt **Verbundene Zellen
zuerst teilen, um Zeilen oder Spalten hinzuzufügen oder zu entfernen.**

## Eine Spalte ausrichten

1. Setzen Sie die Einfügemarke in eine Zelle der Spalte.
2. Wählen Sie in **Tabellenaktionen** unter **Spaltenausrichtung** **Links**, **Zentriert** oder
   **Rechts**. Scrollen Sie dazu im Menü nach unten.

Die ganze Spalte folgt, im Editor und in den Ausgaben.
