Eine Handlungsanweisung ist eine Aufgabe in nummerierten Schritten. Jeder Schritt kann mehr als
seinen Text enthalten: ein Bild, einen Hinweis, einen Sicherheitshinweis, das Ergebnis, zu dem er
führt.

## Eine Handlungsanweisung schreiben

1. Setzen Sie die Einfügemarke dorthin, wo die Handlungsanweisung stehen soll.
2. Tippen Sie <kbd>/</kbd>, dann `hand`, und wählen Sie **Handlungsanweisung**.
3. Tippen Sie den ersten Schritt. Mit <kbd>Eingabe</kbd> kommt der nächste.
4. Drücken Sie <kbd>Eingabe</kbd> in einem leeren letzten Schritt, um die Handlungsanweisung zu
   verlassen.

Der Titel einer Handlungsanweisung ist optional. Wählen Sie oben an ihr **Titel hinzufügen**, um ihr
einen zu geben, etwa „Sicherung wechseln“.

## Unterschritte

- <kbd>Tab</kbd> in einem Schritt macht ihn zum Unterschritt des Schritts davor.
- <kbd>Umschalt</kbd> <kbd>Tab</kbd> in einem Unterschritt holt ihn wieder
  herauf. Die Unterschritte danach kommen mit.

Der erste Schritt kann kein Unterschritt werden: Vor ihm steht kein Schritt.

## Sagen, wozu ein Schritt führt

1. Setzen Sie die Einfügemarke in den Schritt.
2. Tippen Sie <kbd>/</kbd> und wählen Sie **Ergebnis des Schritts**.
3. Tippen Sie das Ergebnis, etwa „Die Abdeckung öffnet sich.“

Das Ergebnis steht unter dem Text des Schritts, markiert mit **Ergebnis**. Ein Schritt hat höchstens
ein Ergebnis.

## Ein Bild in einen Schritt setzen

1. Setzen Sie die Einfügemarke in den Text des Schritts.
2. Wählen Sie **Einfügen** oder tippen Sie <kbd>/</kbd>, und wählen Sie **Bild**. Siehe
   [Bilder](/de/guide/writing/images).

Das Bild steht unter dem Text des Schritts, in diesem Schritt. Ein Hinweis, ein Sicherheitshinweis,
eine Tabelle oder Code kommt genauso in einen Schritt. Ein Seitenumbruch nicht: Er steht nach der
Handlungsanweisung.

## Schritte verschieben

Setzen Sie die Einfügemarke in einen Schritt und drücken Sie <kbd>Alt</kbd> <kbd>↑</kbd> oder <kbd>Alt</kbd> <kbd>↓</kbd>, oder ziehen Sie ihn an seinem Griff. Ein Schritt
wandert unter den Schritten seiner eigenen Handlungsanweisung. Ein Bild in einem
Schritt wandert innerhalb seines Schritts oder in die Schritte daneben. Siehe
[Blöcke verschieben, kopieren und löschen](/de/guide/writing/arranging-blocks).
