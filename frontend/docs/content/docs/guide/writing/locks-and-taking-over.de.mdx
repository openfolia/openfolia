Öffnen Sie ein Modul in einer Überarbeitung im Entwurf, wird es für Sie gesperrt: Die Kopfzeile
zeigt **Von Ihnen gesperrt**. Niemand sonst kann es ändern, bis Ihre Überarbeitung zusammengeführt
oder verworfen ist. So überschreiben zwei Personen nie gegenseitig ihre Arbeit.

## Wenn jemand anderes es bearbeitet

Öffnen Sie ein Modul, das jemand anderes hält, sagt der Editor das: **Jemand anderes bearbeitet
dieses Modul**. Er nennt die Person, seit wann und ihre Überarbeitung.

![Der Dialog Jemand anderes bearbeitet dieses Modul, mit Bearbeitung übernehmen, Zurück und Schreibgeschützt öffnen](/images/guide/de/module-locked.webp)

Wählen Sie eines:

- **Schreibgeschützt öffnen**: Lesen Sie das Modul jetzt. Bearbeiten Sie es, wenn die andere Person
  fertig ist.
- **Zurück**: Gehen Sie dorthin zurück, wo Sie herkamen.
- **Bearbeitung übernehmen**: nur wenn es nicht warten kann, etwa wenn eine Kollegin abwesend ist.

## Die Bearbeitung übernehmen

1. Wählen Sie **Bearbeitung übernehmen**.
2. Beantworten Sie **Warum übernehmen Sie?** Das ist ein Pflichtfeld und wird im Audit-Log
   festgehalten.
3. Wählen Sie erneut **Bearbeitung übernehmen**.

Der Editor der anderen Person wird schreibgeschützt, und sie wird benachrichtigt. Was sie
gespeichert hat, bleibt in ihrer Überarbeitung. Möglicherweise brauchen Sie dafür eine Rolle, die
das Übernehmen erlaubt.

## Wenn Sie das Modul in einer anderen Überarbeitung halten

Der Editor sagt **Sie bearbeiten dieses Modul in einer anderen Überarbeitung**. Wählen Sie:

- **Diese Überarbeitung öffnen**, um dort weiterzumachen.
- **Dort freigeben**, um es stattdessen hier zu bearbeiten. Das geht nur, solange dort nichts daran
  geändert wurde.
