Eine Überarbeitung sammelt Ihre Änderungen. Eine Überarbeitung, die Sie begonnen haben, können Sie
umbenennen, bis sie zusammengeführt ist. Solange sie ein Entwurf ist, können Sie auch eine einzelne
Änderung herausnehmen, ohne den Rest anzufassen.

## Eine Überarbeitung umbenennen

1. Wechseln Sie im Überarbeitungsmenü oben rechts zu der Überarbeitung.
2. Öffnen Sie das Überarbeitungsmenü erneut und wählen Sie **Überarbeitung umbenennen**.
3. Ändern Sie den **Titel** und ergänzen Sie bei Bedarf eine **Beschreibung**.
4. Wählen Sie **Speichern**.

## Eine Änderung aus der Überarbeitung nehmen

Jedes Modul, Handbuch, jeder Begriff und jede Projektdatei, die die Überarbeitung ändert, ist eine
Änderung. Wenn Sie eine herausnehmen, wird alles verworfen, was die Überarbeitung daran getan hat,
gespeichert oder nicht.

1. Wählen Sie **Prüfung** in der Seitenleiste, mit Ihrer Überarbeitung im Entwurf gewählt.
2. Suchen Sie die Änderung in der Liste.
3. Wählen Sie darauf **Aus dieser Überarbeitung nehmen**.
4. Lesen Sie, was passiert, und wählen Sie **Herausnehmen**:
   - in dieser Überarbeitung angelegt: Es wird gelöscht, mit allem, was darin geschrieben wurde;
   - in dieser Überarbeitung geändert: Es wird wieder so, wie es auf main ist;
   - in dieser Überarbeitung gelöscht: Es kommt so zurück, wie es auf main ist.

![Die Rückfrage zum Herausnehmen eines Moduls, das in der Überarbeitung angelegt wurde](/images/guide/de/revision-take-out.webp)

Das lässt sich nicht rückgängig machen. Nur wer die Überarbeitung begonnen hat, nimmt Änderungen
heraus, und nur solange sie ein Entwurf ist.

Um stattdessen eine ältere Version eines Moduls zurückzuholen, siehe
[Der Verlauf eines Moduls](/de/guide/writing/history).
