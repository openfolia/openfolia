An FAQ entry holds a question and its answer. Put several in a row for a page of frequent questions.

## Add an FAQ entry

1. Put the caret where the entry should go.
2. Type <kbd>/</kbd>, then `faq`, and choose **FAQ entry**.
3. Type the question in its first line, **Question**.
4. Type the answer below it. The answer can have several paragraphs and other blocks, such as a
   list or an image.

![An FAQ entry in the editor: the question, the answer under it](/images/guide/en/writing-faq-entry.webp)

There is nothing else to set. The entry moves, copies and deletes like any block. A heading cannot
go inside it.

## What readers see

In the preview and on the portal, readers see the question and open it to read the answer. See
[Preview a module](/guide/writing/preview).
