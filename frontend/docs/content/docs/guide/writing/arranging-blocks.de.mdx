## Über das Aktionsmenü des Blocks

1. Zeigen Sie auf einen Block. Links davon erscheint ein Griff (⠿).
2. Wählen Sie den Griff. Oder setzen Sie die Einfügemarke in den Block und drücken Sie
   <kbd>Umschalt</kbd> <kbd>F10</kbd>.
3. Wählen Sie, was geschehen soll:
   - **Nach oben** oder **Nach unten**: eine Stelle nach oben oder unten.
   - **Duplizieren**: eine Kopie darunter.
   - **Als Textbaustein speichern**: macht daraus eine wiederverwendbare Formulierung. Siehe
     [Textbausteine](/de/guide/writing/snippets).
   - **Löschen**: entfernt ihn. Rückgängig holt ihn zurück.

![Das Aktionsmenü neben einem Absatz](/images/guide/de/block-menu.webp)

## Durch Ziehen

Ziehen Sie einen Block an seinem Griff an die neue Stelle. Eine Linie zeigt, wo er landet. Sie
können einen Block auch aus einem Hinweis oder einer Liste herausziehen.

## Mit der Tastatur

- <kbd>Alt</kbd> <kbd>↑</kbd> und <kbd>Alt</kbd> <kbd>↓</kbd> verschieben den
  Block mit der Einfügemarke (<kbd>⌥</kbd> auf dem Mac). Die Pfeile in der
  Werkzeugleiste tun dasselbe.
- <kbd>Tab</kbd> und <kbd>Umschalt</kbd> <kbd>Tab</kbd> rücken einen Listenpunkt
  ein und aus.
