A new module is created in your revision. Start or choose a draft revision first: see
[Start a revision](/guide/change-sets/start-a-revision).

1. Choose **Content** in the sidebar.
2. Choose **New module** at the top right.
3. Enter a **Title**. Below it you see the ID the module gets: **Saved as clean-the-sensors**.
4. Check the **Source language**: the language you write it in.
5. Choose the **Module type**, such as **Procedure** or **Safety**.
6. Choose the **Audience**: who may read it. Without one, it counts as the most restricted level,
   shown as **Not set: counts as Internal**. See [Audiences](/guide/manuals/audiences).
7. Fill in the fields your project adds, such as **Region**, and add **Keywords** if you like:
   press <kbd>Enter</kbd> or type a comma after each.
8. Choose **Create and open**.

![The New module dialog with a title, the ID made from it and the module type](/images/guide/en/new-module.webp)

The module opens in the editor, empty and locked for you.

## Start from a copy

To begin with the text of another module, tick **Start from a copy of another module** and choose
the **Module to copy**. The new module gets its blocks; the original stays as it is.

## When the title is taken

The ID is made from the title. If a module with that ID exists, the dialog says so. Choose another
title.
