Ein Textbaustein ist eine kurze Formulierung, die Sie immer wieder verwenden, etwa eine
Standardwarnung oder ein Satz zur Gewährleistung. Textbausteine sind Module eines Typs, den Ihr
Projekt als Textbaustein-Typ markiert.

## Einen Textbaustein einfügen

1. Setzen Sie die Einfügemarke dorthin, wo der Textbaustein stehen soll.
2. Wählen Sie **Einfügen** und dann **Textbaustein**. Oder tippen Sie `/textbaustein` und drücken
   Sie <kbd>Eingabe</kbd>.
3. Tippen Sie unter **Textbaustein einfügen** in **Textbausteine suchen** und wählen Sie einen.
4. Wählen Sie, wie er eingefügt wird:
   - **Als Referenz**: bleibt synchron. Eine Änderung am Textbaustein erscheint überall, wo er
     verwendet wird, und er wird einmal übersetzt.
   - **Als Kopie**: Sein Text wird hierher kopiert und lässt sich frei ändern. Nichts verweist
     zurück auf den Textbaustein.
5. Wählen Sie **Einfügen**.

## Einen vorgeschlagenen Textbaustein annehmen

Beim Tippen achtet der Editor auf den Anfang der Formulierung eines Textbausteins. Findet er einen,
zeigt er den Rest des Textbausteins grau hinter der Einfügemarke.

- <kbd>Tab</kbd> fügt ihn als Referenz ein.
- <kbd>Umschalt</kbd> <kbd>Tab</kbd> fügt ihn als Kopie ein.
- <kbd>Esc</kbd> verwirft ihn. Oder tippen Sie einfach weiter.

## Blöcke als Textbaustein speichern

1. Markieren Sie die Blöcke: einen oder einige Absätze oder eine Liste. Ein Textbaustein enthält
   keine Überschriften und keine Modulverweise.
2. Wählen Sie **Als Textbaustein speichern** in der Leiste, die über der Markierung erscheint. Für
   einen einzelnen Block hat das Aktionsmenü (der Griff links) es auch.
3. Geben Sie einen **Titel** ein. Die **ID** wird daraus gebildet.
4. Wählen Sie den **Textbaustein-Typ**, wenn Ihr Projekt mehrere hat.
5. Wählen Sie **Textbaustein speichern**.

Der Textbaustein wird in Ihrer Überarbeitung gespeichert, und ein Verweis darauf tritt an die
Stelle der Blöcke.
