Die Prüfungen suchen, was bei einer Veröffentlichung schiefginge: ein fehlendes Modul, ein
kaputter Link, eine veraltete Übersetzung, eine Seitengestaltung, die nicht passt. Führen Sie sie
aus, bevor Sie eine Überarbeitung einreichen und bevor Sie veröffentlichen.

## Ausführen

- **Für ein Handbuch:** Öffnen Sie es unter **Handbücher**, wählen Sie ⋯ oben rechts und dann
  **Prüfungen ausführen**.
- **Für eine Überarbeitung:** Die Prüfseite einer Überarbeitung zeigt ihre Prüfungen auf einen
  Blick. Wählen Sie sie, um **Prüfungen vor der Veröffentlichung** für das zu öffnen, was die
  Überarbeitung ändert.

![Prüfungen vor der Veröffentlichung für ein Handbuch, mit den Zahlen und der Liste der Warnungen](/images/guide/de/checks.webp)

## Lesen

Die Zeile unter dem Titel sagt, was geprüft wurde, etwa **Handbuch „Operating manual“ in der
Überarbeitung „Batterieanleitung aktualisieren“**. Drei Zahlen folgen:

- **Blockierende Probleme**: Sie verhindern eine Veröffentlichung. Beheben Sie alle.
- **Warnungen**: einen Blick wert. Sie verhindern keine Veröffentlichung.
- **Module ohne Probleme**: wie viele der geprüften Module in Ordnung sind.

Wählen Sie **Alle**, **Blockierend** oder **Warnungen**, um die Liste zu filtern. Jedes Problem
steht unter seinem Modul und seiner Sprache, mit seiner **Prüfung** und seinen **Details**.

## Beheben

1. Wählen Sie **Öffnen** neben einem Problem. Das Modul öffnet sich, oder **Zum Block** bringt Sie
   genau zum Block.
2. Beheben Sie, was die Details sagen.
3. Wählen Sie **Erneut prüfen**.

Die Prüfungen lesen den letzten Speicherpunkt. Der Modul-Editor legt einen an, wenn Sie ein Modul
verlassen. Führen Sie sie darum nach Ihren Änderungen erneut aus.

Blockiert nichts, beginnt **Veröffentlichung erstellen** eine Veröffentlichung des Handbuchs.
