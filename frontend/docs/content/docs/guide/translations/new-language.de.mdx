Ein Modul wird in der Quellsprache geschrieben. Seine Fassung in einer anderen Sprache beginnt als
Kopie der Quelle, die Sie dann Block für Block überschreiben. Jeder Block behält seine ID, so weiß
der Editor, welche Übersetzung zu welchem Quellblock gehört.

## Vom Modul aus beginnen

1. Wählen Sie eine eigene Überarbeitung im Entwurf und öffnen Sie das Modul.
2. Suchen Sie im Tab **Details** die Karte **Übersetzungen**. Sie listet jede Sprache: **Quelle**,
   **Übersetzt**, **Nicht übersetzt** und **In Bearbeitung** für die geöffnete.
3. Wählen Sie **Übersetzen** neben der Sprache.

![Die Karte Übersetzungen: Deutsch in Bearbeitung, Englisch als Quelle, Französisch nicht übersetzt](/images/guide/de/translation-new-language.webp)

Die neue Fassung öffnet sich im Editor, die Quelle daneben. **Quelle** blendet den Quelltext ein
oder aus. Schreiben Sie die Übersetzung über den kopierten Text. Sie wird beim Tippen gespeichert,
wie jede Bearbeitung.

## Vom Übersetzungsstand aus beginnen

1. Wählen Sie **Übersetzungen** in der Seitenleiste.
2. Wählen Sie eine Zelle, die **Nicht übersetzt** zeigt.
3. Wählen Sie in den Details **Übersetzung beginnen**.

Beides braucht eine oben gewählte Überarbeitung im Entwurf. Bearbeitet eine andere Überarbeitung
diese Sprachfassung, sagt der Editor das und beginnt nichts.

## Welche Sprachen es gibt

Die Übersetzungssprachen gehören zu den Projekteinstellungen. Eine Administratorin oder ein
Administrator fügt eine unter **Verwaltung**, **Projekteinstellungen**, **Sprachen** hinzu: die
Sprachkennung in **Sprachkennung, z. B. fr oder pt-BR** eingeben und **Sprache hinzufügen**
wählen. Wie jede Änderung der Einstellungen geschieht das in einer Überarbeitung und wird geprüft.
Ist sie zusammengeführt, erscheint die neue Sprache in der Karte **Übersetzungen** und als Spalte
des Übersetzungsstands.

Eine Sprache, die von rechts nach links geschrieben wird, erhält diese Richtung aus ihrer Schrift.
Siehe [Von rechts nach links schreiben](/de/guide/writing/right-to-left).
