**Reports** answers two questions: how far each manual is translated, and which modules are used
where. Both follow the revision chosen at the top, and both download as CSV.

## How complete each manual is

1. Choose **Reports** in the sidebar. The **Translations** tab opens.
2. Each row is a manual in one language. **Up to date** shows the share of its modules that are
   up to date, as a bar and a percentage.
3. **Status** counts them in words: up to date, outdated, at the agency and missing, for the
   modules and for their blocks.

![The Translations tab of Reports: each manual per language, with its share up to date](/images/guide/en/translation-report.webp)

- **Manual** and **Language** narrow the list. **Clear filters** shows everything again.
- **Open in Translations** opens the translation status filtered to that manual and language.
- **Download CSV** saves the whole report, as filtered, for a spreadsheet.

A manual's page design texts and cover image texts count too.

## Where each module is used

1. Choose the **Usage** tab.
2. Each row is a module, with its **Type**, how many **Manuals** include it and how many
   **Modules** refer to it. **Used in** names the manuals, and says **(through a module
   reference)** where a manual includes it only through another module.

![The Usage tab of Reports: each module, the manuals using it and the modules referring to it](/images/guide/en/translation-usage-report.webp)

- **All**, **Used** and **Unused** choose the modules shown. **Unused** lists the modules no
  manual includes any more: candidates to deprecate or delete.
- **Type** shows one module type. **Sort** orders by **Title**, **Most used** or **Least used**.
- **Download CSV** saves the report, as filtered.

A module used only through a module reference counts as used.
