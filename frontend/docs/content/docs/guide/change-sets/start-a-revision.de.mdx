Sie ändern Inhalte nur in einer Überarbeitung. Eine Überarbeitung sammelt Ihre Änderungen, bis sie
geprüft und zusammengeführt ist. Vorher liest sie niemand sonst.

## Eine Überarbeitung anlegen

1. Öffnen Sie das Überarbeitungsmenü oben rechts.
2. Wählen Sie **Neue Überarbeitung**.
3. Geben Sie einen **Titel** ein: was Sie ändern werden.
4. Wählen Sie **Anlegen**.

![Das Überarbeitungsmenü mit Veröffentlichte Inhalte und Neue Überarbeitung](/images/guide/de/revision-menu.webp)

Das Menü zeigt jetzt Ihre Überarbeitung, und jede Seite liest aus ihr. Ein Modul, das Sie darin
öffnen, wird für Sie gesperrt. So ändert es niemand sonst zur selben Zeit.

## Zu einer anderen Überarbeitung wechseln

1. Öffnen Sie das Überarbeitungsmenü.
2. Tippen Sie in **Überarbeitungen suchen** oder wählen Sie eine aus der Liste. Jede zeigt ihren
   Stand: **Entwurf**, **In Prüfung** oder **Freigegeben**.

Wählen Sie **Veröffentlichte Inhalte**, um wieder zu lesen, was alle lesen. Ihre Überarbeitung
behält ihre Änderungen.

Sie können auch über die Suchpalette wechseln: Drücken Sie <kbd>Strg</kbd> <kbd>K</kbd> und wählen
Sie **Überarbeitung wechseln**.

## Eine Überarbeitung umbenennen

1. Wechseln Sie zu der Überarbeitung.
2. Öffnen Sie das Überarbeitungsmenü und wählen Sie **Überarbeitung umbenennen**.
3. Ändern Sie den **Titel** und ergänzen Sie eine **Beschreibung**: was sie ändert und warum.
4. Wählen Sie **Speichern**.

## Wie es weitergeht

- [Reichen Sie sie zur Prüfung ein](/de/guide/getting-started/first-edit),
  wenn Ihre Änderungen fertig sind.
- [Aktualisieren Sie sie von main](/de/guide/change-sets/update-from-main), wenn andere
  inzwischen Änderungen zusammengeführt haben.
