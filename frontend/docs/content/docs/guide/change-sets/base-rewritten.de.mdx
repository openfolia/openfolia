title: 'Wenn main ersetzt wurde'
description: 'Der Verlauf von main wurde umgeschrieben, seit Ihre Überarbeitung begonnen hat: Verschieben Sie Ihre Änderungen auf den aktuellen Stand von main.'

---

Manchmal ersetzt ein Admin den Verlauf von **main**, etwa nach dem Wiederherstellen einer
Sicherung. Eine Überarbeitung, die vorher begonnen hat, passt dann nicht mehr auf main. Der Editor
sagt das oben auf der Seite: **Der Branch main wurde ersetzt, seit diese Überarbeitung begonnen
hat**.

Ihre Änderungen sind sicher. Aber die Überarbeitung lässt sich so weder aktualisieren noch
zusammenführen: Die Schaltfläche neben dem Überarbeitungsmenü zeigt **Aktualisieren von main nicht
möglich**, und das Zusammenführen ist gesperrt.

## Ihre Änderungen verschieben

Das kann nur, wer die Überarbeitung angelegt hat.

1. Wählen Sie im Hinweis **Meine Änderungen auf den aktuellen Stand von main verschieben**.
2. Warten Sie, während der Editor sie verschiebt. Er legt eine neue Überarbeitung auf dem aktuellen
   Stand von main an, mit Ihren Änderungen darin, und schließt die alte.
3. Der Editor wechselt von selbst zur neuen Überarbeitung. Eine Meldung sagt, dass Ihre Änderungen
   jetzt auf dem aktuellen Stand von main liegen. Wurden sie schon verschoben, etwa in einem anderen
   Tab, bietet die Meldung stattdessen **Öffnen** an.

Für die neue Überarbeitung beginnt die Prüfung von vorn: Reichen Sie sie zur Prüfung ein, wenn sie
fertig ist.

## Wenn einige Änderungen nicht passen

Eine Datei kann sich auch auf dem aktuellen Stand von main geändert haben. Der Editor lässt diese
Datei dann so, wie main sie hat, und die Schaltfläche zeigt **Von Hand eintragen** mit der Zahl der
Dateien. Ein Dialog listet sie: **Einige Änderungen brauchen Sie auf dem aktuellen Stand von
main**.

1. Wählen Sie **Öffnen** neben jeder Datei. Die Liste zählt die Blöcke, die Sie darin geändert
   haben.
2. Tragen Sie Ihre Änderungen erneut ein und lassen Sie die Datei speichern.
3. Wählen Sie **Fertig**, wenn jede Datei erledigt ist.

## Die Überarbeitung einer anderen Person

Ist die Überarbeitung nicht Ihre, sagt der Hinweis, dass ihre Autorin oder ihr Autor die Änderungen
verschiebt. Sagen Sie ihr oder ihm Bescheid, oder warten Sie.
