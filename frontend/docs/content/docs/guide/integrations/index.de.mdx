Dieser Abschnitt richtet sich an Entwicklerinnen und Entwickler, die andere Systeme an die
freigegebenen Inhalte anbinden: ein Portal, eine App, einen Suchindex oder einen KI-Assistenten.
Für das Schreiben und Prüfen brauchen Sie ihn nicht. Beginnen Sie mit
[Die Delivery-API](/de/guide/integrations/delivery-api).

Die [API-Referenz](/de/api) hat eine Seite je Route, aus dem Server erzeugt, und beide
OpenAPI-Dokumente zum Herunterladen. Zwei Anleitungen beschreiben eine ganze Anbindung:
[Anbindung an eine RAG-Pipeline](/de/guides/rag) und [der MCP-Server](/de/guides/mcp) für
KI-Assistenten. Eine Veröffentlichung als [iiRDS-Paket](/de/guide/releases/iirds) oder als
[DITA-Projekt](/de/guide/releases/dita) steht unter Veröffentlichungen.

Im Editor richtet eine Administratorin oder ein Administrator ein, was Integrationen nutzen:
Service-Accounts mit ihren Tokens und Webhooks. Siehe [Verwaltung](/de/guide/admin).
