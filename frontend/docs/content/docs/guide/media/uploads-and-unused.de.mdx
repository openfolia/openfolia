Dateien kommen in eine Überarbeitung, wie jede andere Änderung. Eine Datei, die niemand mehr
verwendet, lässt sich löschen, sobald seit ihrem Hochladen ein Tag vergangen ist.

## Hochladen

1. Wählen Sie oben eine eigene Überarbeitung im Entwurf. Die Uploads landen darin.
2. Wählen Sie **Medien** in der Seitenleiste, dann **Hochladen**.
3. Wählen Sie eine oder mehrere Dateien. **Laufende Uploads** zeigt jede mit ihrem Fortschritt.
4. Eine Meldung sagt, wenn sie da ist: **picture.png wurde in die Überarbeitung hochgeladen.**

Ein PNG oder JPEG kommt als Bild hinein. Jede andere Datei kommt als Anhang hinein, außer Typen,
die Code ausführen könnten, etwa Webseiten, SVG oder Programme. Die Datei zeigt **Noch nicht
verwendet**, bis ein Modul sie nennt.

Sie können auch hochladen, während Sie in einem Modul ein Bild oder einen Anhang einfügen. Siehe
[Bilder](/de/guide/writing/images) und [Eine Datei anhängen](/de/guide/writing/attachments).

## Die Dateien finden, die niemand verwendet

1. Wählen Sie in **Medien** **Verwendung**, dann **Unbenutzt**.
2. Die Liste zeigt die Dateien, die kein Modul, keine Anleitung, keine Veröffentlichung und keine offene Überarbeitung
   verwendet und die vor mehr als 24 Stunden hochgeladen wurden.

Ist die Liste leer, sagt sie **Jede Datei wird irgendwo verwendet oder wurde in den letzten 24
Stunden hochgeladen.**

## Eine Datei löschen

1. Wählen Sie in der Liste **Unbenutzt** die Datei.
2. Wählen Sie in den **Dateidetails** **Löschen**.
3. Die Datei verschwindet aus der Liste. Eine Meldung bietet kurz **Rückgängig** an. Erst wenn sie
   endet, wird die Datei gelöscht.

Hat inzwischen jemand die Datei verwendet, bleibt sie, und die Meldung nennt, wo sie verwendet
wird. Zum Löschen von Dateien sind Bearbeitungsrechte für alle Inhalte nötig.

## Warum sich eine Datei nicht löschen lässt

Die Details einer Datei sagen, warum es kein **Löschen** gibt:

![Die Details eines frischen Uploads: Noch verwendet sie kein Modul, und solange ihre Überarbeitung offen ist, lässt sie sich nicht löschen](/images/guide/de/media-uploads.webp)

- **Sie steht nicht in der Liste der unbenutzten Dateien und kann darum nicht gelöscht werden: Sie
  wurde in die offene Überarbeitung … hochgeladen und gilt als verwendet, solange die Überarbeitung
  offen ist.** Führen Sie diese Überarbeitung zuerst zusammen oder verwerfen Sie sie.
- **Sie steht nicht in der Liste der unbenutzten Dateien und kann darum nicht gelöscht werden: Sie
  wird anderswo noch verwendet oder wurde vor weniger als 24 Stunden hochgeladen.** Warten Sie
  einen Tag, oder sehen Sie nach, wo sie verwendet wird.
- **Zum Löschen von Dateien sind Bearbeitungsrechte für alle Inhalte nötig.** Fragen Sie jemanden
  mit Administrationsrechten.

**In der Liste der unbenutzten Dateien anzeigen** springt dort zur Datei, wenn sie sich löschen
lässt.
