Modules can attach files for readers to download: a sample configuration, a PDF data sheet, a ZIP
of drivers. The media library lists them beside the images.

## List the attached files

1. Choose **Media** in the sidebar.
2. Choose **Type**, then **Attachments**. Or choose one file type, such as **PDF** or **ZIP**.
3. Choose **Table** to see each file's **Name**, **Type**, **Size**, **Languages** and **Usage**.

Search with **Search by alt text, module or file name**: it finds a file by its name or by the
modules that attach it.

## Download one

1. Choose the file. **File details** open.
2. Choose **Download**. The file is saved as it was uploaded.

The details show its **Type** and **Size**, and **Used in** lists the modules that attach it, per
language. Choose a module to open it at the attachment.

## Add or remove one

You attach a file in the module itself, and can upload it there. See
[Attach a file](/guide/writing/attachments). A file no module attaches any more shows up under
**Unused** a day later, and can be deleted. See
[Upload and clean up files](/guide/media/uploads-and-unused).
