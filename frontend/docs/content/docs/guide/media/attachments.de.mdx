Module können Dateien anhängen, die Lesende herunterladen: eine Beispielkonfiguration, ein
PDF-Datenblatt, ein ZIP mit Treibern. Die Medienbibliothek listet sie neben den Bildern.

## Die angehängten Dateien auflisten

1. Wählen Sie **Medien** in der Seitenleiste.
2. Wählen Sie **Typ**, dann **Anhänge**. Oder wählen Sie einen Dateityp, etwa **PDF** oder
   **ZIP**.
3. Wählen Sie **Tabelle**, um für jede Datei **Name**, **Typ**, **Größe**, **Sprachen** und
   **Verwendung** zu sehen.

Suchen Sie mit **Nach Alternativtext, Modul oder Dateiname suchen**: Das findet eine Datei über
ihren Namen oder über die Module, die sie anhängen.

## Eine herunterladen

1. Wählen Sie die Datei. Die **Dateidetails** öffnen sich.
2. Wählen Sie **Herunterladen**. Die Datei wird gespeichert, wie sie hochgeladen wurde.

Die Details zeigen ihren **Typ** und ihre **Größe**, und **Verwendet in** listet die Module, die
sie anhängen, je Sprache. Wählen Sie ein Modul, um es am Anhang zu öffnen.

## Eine hinzufügen oder entfernen

Eine Datei hängen Sie im Modul selbst an und können sie dort hochladen. Siehe
[Eine Datei anhängen](/de/guide/writing/attachments). Eine Datei, die kein Modul mehr anhängt,
erscheint einen Tag später unter **Unbenutzt** und lässt sich löschen. Siehe
[Dateien hochladen und aufräumen](/de/guide/media/uploads-and-unused).
