Die Logos und Icons des Brandings sind eigene Bilder, getrennt von den Medien der Inhalte. Sie
werden unter **Verwaltung**, **Branding** hochgeladen und zählen wie jede andere Datei zum
Speicherlimit.

## Ein Logo oder Icon hochladen

1. Wählen Sie **Verwaltung** in der Seitenleiste, dann **Branding**.
2. Wählen Sie unter **Logos und Icons** **Hochladen** neben einem Feld: **Logo**, **Logo auf
   dunklen Seiten**, **Bildmarke**, **Favicon** oder **App-Icon**. **Ersetzen** ändert eines, das
   gesetzt ist.
3. Wählen Sie die Datei. Das Bild erscheint im Feld und überall, wo es verwendet wird, für alle
   beim nächsten Laden.

![Die Karte Logos und Icons: Logo, Bildmarke und Icons, jeweils mit Hochladen](/images/guide/de/media-branding.webp)

Die Datei muss sein:

- ein PNG oder WebP. SVG wird nicht angenommen: als PNG exportieren.
- höchstens 1 MB und 4096 Pixel pro Seite.
- ein einzelnes Standbild. Ein animiertes PNG oder WebP wird abgelehnt: **Das Bild muss ein
  einzelnes Standbild sein: Animierte PNG- oder WebP-Dateien werden nicht angenommen.**
- quadratisch, für das **Favicon** und das **App-Icon**.

Eine abgelehnte Datei wird nicht behalten, und das Feld behält, was es hatte. Der Grund steht unter
dem Feld.

## Bilder, die kein Feld verwendet

**Entfernen** nimmt ein Bild aus seinem Feld; das Feld zeigt wieder den Standard. Ein Bild, das
kein Feld verwendet, wird einen Tag nach dem Hochladen von selbst entfernt. Dieselbe Datei erneut
hochzuladen speichert nichts Neues.

Das Branding fasst eine begrenzte Zahl neuer Bilder. Ist es voll, meldet der Editor **Das Branding
enthält bereits so viele neue Bilder, wie es kann (200). Bilder, die kein Feld verwendet, werden
einen Tag nach dem Hochladen entfernt.** Warten Sie einen Tag, dann laden Sie erneut hoch.

Ein Bild des Brandings zählt zum [Speicherlimit](/de/guide/media/storage-usage) der Installation.
Über dem Limit wird der Upload abgelehnt.

Zu Produktname und Farben siehe [Branding](/de/guide/admin/branding).
