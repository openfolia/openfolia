---
title: 'Betrieb'
description: 'Eine Instanz betreiben und warten.'
articleId: 'guide.self-hosting'
---

Dieser Abschnitt richtet sich an die Person, die den Server betreibt. Für das Schreiben, Prüfen,
Übersetzen und Verwalten brauchen Sie ihn nicht. Beginnen Sie mit
[Was läuft](/de/guide/self-hosting/overview) und dem
[Schnellstart](/de/guide/self-hosting/quick-start).

Zwei Referenzen werden aus dem Quellcode erzeugt: Die
[Einstellungsreferenz](/de/reference/settings) nennt jede Einstellung, ihr Format und ihren
Standard, die [Fehlercodes](/de/reference/errors) sagen, was jeder Fehler bedeutet, den der Server
meldet. [Konfiguration](/de/configuration) unterscheidet die Einstellungen des Servers von der
`openfolia.yaml` jedes Inhalts-Repositorys.

Was eine Administratorin oder ein Administrator im Editor erledigt (Benutzer, Backups, die
Systemseite), steht unter [Verwaltung](/de/guide/admin).
