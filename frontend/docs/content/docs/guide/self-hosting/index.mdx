This section is for the person who runs the server. Writers, reviewers, translators and admins do
not need it. Start with [What runs](/guide/self-hosting/overview) and the
[Quick start](/guide/self-hosting/quick-start).

Two references are generated from the source code: the [settings reference](/reference/settings)
lists every setting, its format and its default, and the [error codes](/reference/errors) say
what each error the server answers means. [Configuration](/configuration) tells the server's
settings apart from each content repository's `openfolia.yaml`.

What an admin does in the editor (users, backups, the system page) is under
[Admin](/guide/admin).
