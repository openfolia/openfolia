The user guide explains the editor to the people who work in it: writers, reviewers, translators
and admins. Each page has a stable article ID, so the editor's in-app help
links to it by ID (`/guide-index.json`).

Start with [Almost everything is content](/guide/getting-started/content): modules, manuals,
settings, page designs and terms all change the same way, in a revision that is reviewed.
