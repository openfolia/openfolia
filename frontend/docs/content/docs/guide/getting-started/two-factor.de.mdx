---
title: 'Zwei-Faktor-Anmeldung'
description: 'Einen zweiten Schritt mit einer Authenticator-App einschalten, Wiederherstellungscodes sichern und sich damit anmelden.'
articleId: 'guide.getting-started.two-factor'
---

Mit der Zwei-Faktor-Anmeldung brauchen Sie zum Anmelden einen Code von Ihrem Telefon, zusätzlich zu
Ihrem Passwort oder zum Code, den wir Ihnen per E-Mail senden. Wer Ihr Passwort erfährt, kann sich
damit allein nicht anmelden.

Sie ist für alle, die sich hier anmelden, mit einem Passwort oder einem Code per E-Mail. Melden Sie
sich mit dem Konto Ihrer Organisation an (Single Sign-on), verlangt der Anmeldedienst Ihrer
Organisation seinen eigenen zweiten Faktor, und das Kontomenü bietet diesen nicht an.

## Einschalten

Sie brauchen eine Authenticator-App auf Ihrem Telefon: jede App, die sechsstellige Codes zeigt, die
alle 30 Sekunden wechseln.

1. Öffnen Sie das Kontomenü und wählen Sie **Zwei-Faktor-Anmeldung**.
2. Geben Sie Ihr Passwort ein, wenn Sie eines haben, und wählen Sie **Einrichten**.
3. Scannen Sie den QR-Code mit der App. Geht das nicht, geben Sie den Schlüssel daneben in der App
   ein.
4. Geben Sie den Code ein, den die App zeigt, und wählen Sie **Einschalten**.
5. Sichern Sie Ihre zehn Wiederherstellungscodes: **Codes kopieren** oder **Herunterladen**. Sie
   werden nur jetzt angezeigt.

Ihre anderen Sitzungen enden; diese läuft weiter.

## Anmelden

1. Melden Sie sich wie gewohnt an. Die Seite **Zwei-Faktor-Anmeldung** fragt dann nach einem Code.
2. Geben Sie die sechs Ziffern ein, die die App zeigt. Sie können sie einfügen, mit oder ohne
   Leerzeichen.

Jeder Code funktioniert einmal. Der zweite Schritt bleibt zehn Minuten offen, in dem Browser, in dem
Sie begonnen haben. Danach sagt die Seite **Melden Sie sich neu an**. Auch eine Einladung, ein Link
zum Zurücksetzen und ein Code per E-Mail fragen danach.

Nach zu vielen falschen Codes sagt die Seite, wie lange Sie warten müssen.

## Ohne Telefon anmelden

1. Wählen Sie auf der Seite **Zwei-Faktor-Anmeldung** **Wiederherstellungscode verwenden**.
2. Geben Sie einen Ihrer Wiederherstellungscodes ein. Jeder funktioniert einmal.

Auch keine Codes mehr? Bitten Sie Ihren Admin, Ihre Zwei-Faktor-Anmeldung zurückzusetzen.

## Neue Wiederherstellungscodes oder ausschalten

1. Öffnen Sie das Kontomenü und wählen Sie **Zwei-Faktor-Anmeldung**. Dort steht, wie viele
   Wiederherstellungscodes übrig sind.
2. Wählen Sie **Neue Wiederherstellungscodes** oder **Ausschalten**.
3. Geben Sie Ihr Passwort oder einen aktuellen Code ein.

Neue Codes ersetzen die früheren. Für ein neues Telefon schalten Sie sie aus und richten sie neu
ein.

## Wenn sie vorgeschrieben ist

Ihr Admin kann sie vorschreiben. Haben Sie sie noch nicht, kommt bei Ihrer nächsten Anmeldung nach
dem Passwort die Seite **Zwei-Faktor-Anmeldung einrichten**. Angemeldet sind Sie, sobald sie an ist
und Ihre Wiederherstellungscodes angezeigt werden. Schalten Sie sie aus, richten Sie sie bei Ihrer
nächsten Anmeldung neu ein.
