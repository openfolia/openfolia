Öffnen Sie die Adresse des Editors im Browser. Die Seite **Anmelden** zeigt die Wege, die Ihre
Installation anbietet. Welche es gibt, entscheidet Ihr Admin.

## Anmelden

Nutzen Sie den Weg, den Ihre Seite zeigt:

- **Mit dem Konto Ihrer Organisation:** Wählen Sie **Mit … anmelden** (der Name des
  Anmeldedienstes Ihrer Organisation) oder **Mit Single Sign-on (SAML) anmelden**. Melden Sie sich
  dort an. Danach kommen Sie zurück in den Editor.
- **Mit Passwort:** Geben Sie **E-Mail-Adresse** und **Passwort** ein und wählen Sie **Anmelden**.
  Passwort vergessen? Wählen Sie **Passwort vergessen?** und folgen Sie dem Link in der E-Mail. Der
  Link funktioniert einmal, eine Stunde lang.
- **Mit einem Code per E-Mail:** Wählen Sie **Code per E-Mail senden** und geben Sie Ihre
  E-Mail-Adresse ein. Tippen Sie den sechsstelligen Code aus der E-Mail ein oder öffnen Sie ihren
  Link. Der Code funktioniert einmal, einige Minuten lang (10, wenn Ihr Admin keine andere Zeit eingestellt hat).
  Manche Installationen bieten nur diesen Weg an: Dann zeigt die Seite allein **Code per E-Mail
  senden**.
- **Notfallanmeldung** (nur wo Ihre Organisation Single Sign-on vorschreibt): für ein von den Admins
  benanntes Konto, mit seinem Passwort, falls der Anmeldedienst nicht funktioniert. Siehe
  [Single Sign-on vorschreiben](/de/guide/admin/single-sign-on).
- **Als Demo-Benutzer** (nur in Demo-Installationen): Wählen Sie unter **Demo-Benutzer** eine
  Person. Jede hat andere Rollen. So sehen Sie, was eine schreibende, eine prüfende Person oder ein
  Admin sieht.

Mit eingeschalteter [Zwei-Faktor-Anmeldung](/de/guide/getting-started/two-factor) fragt die nächste
Seite nach einem Code aus Ihrer Authenticator-App.

Nach dem Anmelden sehen Sie **Inhalte** oder die Seite, die Sie aufgerufen haben.

## Das Passwort über einen Link setzen

Eine Einladung oder ein Link zum Zurücksetzen öffnet die Seite **Willkommen, …** oder **Neues
Passwort wählen**.

1. Geben Sie ein **Neues Passwort** ein: mindestens 12 Zeichen. Ein paar Wörter, die nicht
   zusammengehören, ergeben ein gutes.
2. Geben Sie es unter **Passwort wiederholen** noch einmal ein.
3. Wählen Sie **Passwort setzen und anmelden**.

Sie sind sofort angemeldet. Nach dem Zurücksetzen enden Ihre anderen Sitzungen. Ein Link
funktioniert einmal: Zeigt die Seite **Dieser Link funktioniert nicht** oder **Dieser Link ist
abgelaufen**, bitten Sie Ihren Admin um einen neuen oder nutzen Sie **Passwort vergessen?** auf der
Anmeldeseite.

## Das Passwort ändern

Nur sichtbar, wenn Sie sich mit einem Passwort angemeldet haben.

1. Öffnen Sie das Kontomenü und wählen Sie **Passwort ändern**.
2. Geben Sie Ihr **Aktuelles Passwort** ein, dann das **Neue Passwort** und es noch einmal unter
   **Neues Passwort wiederholen**.
3. Wählen Sie **Passwort ändern**.

Ihre anderen Sitzungen enden; diese läuft weiter.

## Abmelden

1. Öffnen Sie das Kontomenü: Wählen Sie Ihren Namen unten in der Seitenleiste.
2. Wählen Sie **Abmelden**.

Eine Demo-Installation hat kein **Abmelden**. Nutzen Sie stattdessen **Benutzer wechseln** im
Kontomenü.

## Wenn Ihre Sitzung endet

Eine Sitzung endet nach einer Zeit ohne Aktivität und spätestens einige Tage nach der Anmeldung. Die
Anmeldeseite sagt dann, dass Ihre Sitzung beendet ist. Melden Sie sich wieder an: Sie kommen auf die
Seite zurück, auf der Sie waren. In einem Modul getippter, noch nicht gespeicherter Text bleibt in
Ihrem Browser und wird wieder angeboten.

## Wenn die Anmeldung nicht klappt

Fragen Sie Ihren Admin. Er kann Ihnen eine neue Einladung oder einen Link für ein neues Passwort
schicken oder Ihr Konto wieder aktivieren. Haben Sie Ihr Telefon verloren, kann er
Ihre [Zwei-Faktor-Anmeldung](/de/guide/getting-started/two-factor) zurücksetzen.
