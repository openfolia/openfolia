The editor uses a few words again and again. Learn them first.

## Module

A module is one piece of content: a procedure, a safety notice, a description. It has a title, a
type and blocks: text, lists, tables, images, notices, steps. You write a module once and use it in
many manuals.

Each module has an ID, made from its title when you create it (`replace-battery`). Other modules and
manuals name it by this ID.

## Language

A module is written in a source language. Translations are versions of the same module in other
languages. The editor shows which languages are up to date and which need translating.

## Variant

A product often comes in variants: a small and a large model, say. Variant attributes (such as
**Model**) and their values (such as **Large**) are set in the project's settings. A variant block
in a module holds text that only some variants get.

## Manual

A manual puts modules in an order, with chapters. It is built for one or more variants and an
audience. The editor makes a portal page and a PDF from it. A derived manual, such as a safety
leaflet, gathers its modules from another manual.

## Revision

You never edit the published content directly. You start a revision, make your changes in it and
send it for review. Until then, nobody else sees your changes. **Published content** is what
everyone reads.

## Review

A reviewer reads the changes of a revision and approves them, or asks for changes. After approval,
a publisher merges the revision into the published content.

## Release

A release freezes the published content of a product at one point. Its PDFs and portal pages are
made then, and they never change afterwards.
