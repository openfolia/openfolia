Diese Seite führt Sie durch eine kleine Änderung: Sie legen eine Überarbeitung an, ändern ein Modul
und reichen es zur Prüfung ein. Sie brauchen eine Rolle, die Inhalte bearbeiten darf, etwa
**Author**.

## 1. Eine Überarbeitung anlegen

1. Öffnen Sie das Überarbeitungsmenü oben rechts. Es zeigt **Veröffentlichte Inhalte**.
2. Wählen Sie **Neue Überarbeitung**.
3. Geben Sie einen **Titel** ein, der sagt, was Sie ändern, etwa „Batterieanleitung
   aktualisieren“.
4. Wählen Sie **Anlegen**.

![Das Überarbeitungsmenü, in dem eine neue Überarbeitung angelegt wird](/images/guide/de/revision-new.webp)

Das Menü zeigt jetzt Ihre Überarbeitung. Alles, was Sie ändern, landet darin.

## 2. Ein Modul öffnen

1. Wählen Sie **Inhalte** in der Seitenleiste.
2. Suchen Sie das Modul: Tippen Sie in **Titel und IDs durchsuchen** oder wählen Sie links eine
   Gruppe.
3. Wählen Sie den Titel des Moduls.

Das Modul öffnet sich im Editor. Die Kopfzeile zeigt **Von Ihnen gesperrt**: Niemand sonst kann
dieses Modul ändern, bis Ihre Überarbeitung abgeschlossen ist.

## 3. Den Text ändern

1. Klicken Sie in den Text und tippen Sie.
2. Achten Sie auf die Kopfzeile: Sie zeigt **Wird gespeichert …**, dann **Gespeichert**. Eine
   Speichern-Schaltfläche gibt es nicht.

Unter [Ein Modul bearbeiten](/de/guide/writing/edit-a-module) steht alles, was der Editor kann.

## 4. Zur Prüfung einreichen

1. Wählen Sie **Prüfung** in der Seitenleiste.
2. Wählen Sie **Entwürfe** und dann Ihre Überarbeitung. Sie sehen jede Änderung darin.
3. Wählen Sie **Zur Prüfung einreichen**.

![Die Prüfseite einer Überarbeitung, unten rechts Zur Prüfung einreichen](/images/guide/de/review-submit.webp)

Die Überarbeitung ist jetzt **In Prüfung**. Die prüfenden Personen erfahren davon. Gibt eine sie
frei, führt eine veröffentlichende Person sie mit den veröffentlichten Inhalten zusammen. Fordert
sie Änderungen an, kommt die Überarbeitung als Entwurf zu Ihnen zurück: Ändern Sie, was verlangt
wurde, und reichen Sie sie erneut ein.
