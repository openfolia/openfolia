---
title: 'Benutzerhandbuch'
description: 'Für Schreibende, Prüfende, Übersetzende und Admins: den Editor ohne Schulung lernen.'
articleId: 'guide'
---

Das Benutzerhandbuch erklärt den Editor für die Menschen, die darin arbeiten: Schreibende,
Prüfende, Übersetzende und Admins. Jede Seite hat eine feste Artikel-ID,
über die die Hilfe im Editor auf sie verweist (`/guide-index.json`).

Beginnen Sie mit [Fast alles ist Inhalt](/de/guide/getting-started/content): Module, Handbücher,
Einstellungen, Seitengestaltungen und Begriffe ändern sich alle gleich, in einer Überarbeitung, die
geprüft wird.
