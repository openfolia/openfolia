**Verwaltung › Varianten** ist die eigene Seite der Variantenmerkmale. Sie enthält denselben Editor
wie das Thema **Variantenmerkmale** der Projekteinstellungen. Wie Sie Merkmale und Werte anlegen,
umbenennen, ordnen und archivieren: [Variantenmerkmale](/de/guide/variants/attributes).

## Was die Seite ergänzt

- **Neuer Wert** oben rechts fügt einem Merkmal einen Wert hinzu.
- Die Leiste über dem Editor sagt, in welche Überarbeitung die Änderungen gespeichert werden, und
  bietet **In Prüfung öffnen** und **Zur Prüfung einreichen**.
- **Zur Prüfung einreichen** sagt, welche Freigaben die Änderung braucht, bevor sie zusammengeführt
  werden kann: eine Prüfung und eine Freigabe für jeden eingeschränkten Modultyp. Bis eine Prüferin
  oder ein Prüfer sie zurückgibt, lässt sie sich nicht mehr ändern.

Ohne Überarbeitung zeigt die Seite die Merkmale und sagt „Wählen oder beginnen Sie eine
Überarbeitung, um die Projekteinstellungen zu ändern“.
