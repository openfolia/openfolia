**Admin › Variants** is the variant attributes' own page. It holds the same editor as the
**Variant attributes** topic of the project settings. How to add, rename, order and archive
attributes and values: [Variant attributes](/guide/variants/attributes).

## What the page adds

- **New value** at the top right adds a value to an attribute.
- The bar above the editor says which revision the changes are saved into, and offers **Open in
  review** and **Submit for review**.
- **Submit for review** says which approvals the change needs before it can be merged: a review,
  and a sign-off for each restricted module type. Until a reviewer sends it back, it can no longer
  be changed.

Without a revision, the page shows the attributes and says “Choose or start a revision to change
the project settings”.
