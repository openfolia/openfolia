title: 'Service-Accounts und Tokens'

Ein Service-Account ist ein maschineller Client, etwa ein Portal-Build, eine Pipeline oder ein
Agent. Er hat Rollen wie eine Person und ruft die API mit eigenen Tokens auf. Ein Token wird
einmal angezeigt, wenn es ausgestellt wird.

## Einen Service-Account hinzufügen

1. Öffnen Sie **Verwaltung**, dann **Service-Accounts**.
2. Wählen Sie **Neuer Service-Account**.
3. Füllen Sie **Name** und, wenn Sie möchten, **Beschreibung** aus. Die **Service-Account-ID**
   entsteht aus dem Namen. Sie kann später nicht geändert werden.
4. Wählen Sie unter **Rollen** seine Rollen. Rollen, die Zugriffe verwalten (**admin.roles**),
   werden nicht angeboten.
5. Wählen Sie **Service-Account hinzufügen**.

## Ein Token ausstellen

1. Wählen Sie in der Zeile des Service-Accounts **Tokens**.
2. Wählen Sie **Token ausstellen**.
3. Geben Sie unter **Wofür es dient** an, wohin das Token geht, etwa „Portal-Build, Produktion“.
   Das erscheint in der Liste und im Audit-Log.
4. Wählen Sie unter **Gültigkeit**, wie lange es gilt: 30, 90, 180 oder 365 Tage.
5. Wählen Sie **Ausstellen**.
6. **Kopieren Sie das Token jetzt**: Wählen Sie **Token kopieren** und hinterlegen Sie es dort, wo
   sein Client es liest. Wählen Sie dann **Fertig**.

![Die Tokens eines Service-Accounts, mit einem neuen Token, einmal zum Kopieren angezeigt](/images/guide/de/admin-service-token.webp)

Das Token lässt sich nicht erneut anzeigen, auch hier nicht. Geht es verloren, stellen Sie ein
neues aus und widerrufen das alte.

Die Liste zeigt für jedes Token den Namen, den Ablauf, die letzte Verwendung und den Zustand: **Aktiv**,
**Abgelaufen** oder **Widerrufen**. Stellen Sie für jeden Client, der die API aufruft, ein eigenes
Token aus, damit Sie eines widerrufen können, ohne die anderen anzuhalten.

## Ein Token widerrufen

Wählen Sie neben dem Token **Widerrufen** und bestätigen Sie. Jeder Client, der es verwendet, wird
ab seiner nächsten Anfrage abgewiesen. Ein widerrufenes Token lässt sich nicht wiederherstellen.

## Einen Service-Account deaktivieren

Wählen Sie in seiner Zeile **Deaktivieren** und bestätigen Sie. Keines seiner Tokens kann mehr
handeln, und alle Sperren, die er hält, werden aufgehoben. Rollen und Tokens bleiben erhalten:
**Reaktivieren** bringt die Tokens zurück, die weder widerrufen noch abgelaufen sind.
