**Verwaltung** in der Seitenleiste öffnet die Administration. Ihre Seiten stehen links in einer
Leiste, unter fünf Überschriften. Jede Seite ist einen Klick entfernt.

## Die Leiste

| Gruppe                   | Seiten                                                                 |
| ------------------------ | ---------------------------------------------------------------------- |
| **Personen und Zugriff** | **Benutzer**, **Rollen**, **Gruppenzuordnungen**, **Service-Accounts** |
| **Inhalte**              | **Projekteinstellungen**, **Varianten**, **Seitengestaltung**          |
| **Erscheinungsbild**     | **Branding**                                                           |
| **Integrationen**        | **Webhooks**                                                           |
| **Betrieb**              | **System**, **Backups**, **Audit-Log**                                 |

![Die Seite Benutzer mit der Leiste der Verwaltung und ihren fünf Gruppen links](/images/guide/de/admin-users.webp)

Die geöffnete Seite ist in der Leiste markiert, ihr Name ist die Überschrift. Die Hauptaktion
einer Seite, etwa **Neuer Benutzer** oder **Abonnenten hinzufügen**, steht oben rechts.

**Projekteinstellungen** hat eine eigene zweite Liste: ein Thema pro Seite. Siehe
[Projekteinstellungen](/de/guide/admin/project-settings).

## Nur die Seiten, die Ihre Rolle öffnet

Die Leiste zeigt nur die Seiten, die Ihre Rolle öffnen darf. Eine Gruppe ohne solche Seiten
entfällt. Wer nur Webhooks verwalten darf, sieht **Integrationen** mit **Webhooks** allein, und
**Verwaltung** öffnet diese Seite.

Ein Link auf eine Seite, die Ihre Rolle nicht öffnen darf, zeigt **Kein Zugriff** und nennt die
nötige Berechtigung. [Rollen und Berechtigungen](/de/guide/reference/roles) listet, was jede
Berechtigung öffnet.

## Auf dem Telefon

Auf einem schmalen Bildschirm wird die Leiste zu einer Auswahl über der Seite, **Bereiche der
Verwaltung**. Sie listet dieselben Seiten unter denselben Gruppen. Wählen Sie eine Seite, um sie
zu öffnen.

## Eine Verwaltungsseite über die Suchpalette öffnen

Jede Verwaltungsseite und jedes Thema der Projekteinstellungen steht auch in der Suchpalette.

1. Drücken Sie <kbd>Strg</kbd> <kbd>K</kbd> (<kbd>⌘</kbd> <kbd>K</kbd> auf dem Mac).
2. Tippen Sie den Namen der Seite, etwa `Sprachen` oder `Webhooks`.
3. Unter **Seiten** zeigt jedes Ergebnis, wo es liegt, etwa **Verwaltung › Projekteinstellungen ›
   Sprachen**. Wählen Sie es.

![Die Suchpalette mit zwei Themen der Einstellungen unter Seiten](/images/guide/de/admin-palette.webp)

Die Palette listet nur die Seiten, die Ihre Rolle öffnet. Den Rest der Palette beschreibt
[Suchen](/de/guide/getting-started/search).
