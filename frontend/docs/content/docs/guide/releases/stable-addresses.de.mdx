Jede veröffentlichte Anleitung hat für jedes Produkt, jede Variante und jede Sprache eine
dauerhafte Adresse. Drucken Sie sie auf ein Produkt, ein Etikett oder einen Umschlag, oder
verlinken Sie sie: Sie öffnet immer die neueste Veröffentlichung des Produkts, der Link veraltet
also nie.

## Die Adresse einer Datei finden

1. Wählen Sie **Veröffentlichungen** in der Seitenleiste, dann die Veröffentlichung, dann
   **Dateien und Änderungen**.
2. Wählen Sie unter **Dateien** **Adresse** in der Zeile der Datei.

Der Dialog zeigt zwei Adressen, jede mit **Kopieren**:

- **Neueste Veröffentlichung:** öffnet die neueste Veröffentlichung dieses Produkts. Diese Adresse gehört
  auf Produkte, Etiketten und Umschläge.
- **Diese Veröffentlichung:** öffnet immer genau diese Veröffentlichung, auch wenn es neuere gibt.

![Der Adressdialog: die neueste Adresse, die dieser Veröffentlichung und der QR-Code](/images/guide/de/release-address.webp)

## Auf der Seite der Anleitung

Auch die Seite der Anleitung führt ihre Adressen auf, unter **Dauerhafte Adressen**: eine Zeile
pro Produkt und Variante, in der gewählten Sprache. **Adresse** in einer Zeile öffnet denselben
Dialog. Eine Anleitung bekommt ihre Adressen, sobald eine Veröffentlichung sie enthält.

## Wie die Adresse aufgebaut ist

Eine Adresse nennt Produkt, Anleitung, Variante und Sprache, etwa
`/d/north/operating/model=small/en`. Die Adresse einer bestimmten Veröffentlichung hängt ihre
Version an: `…/en@2.0`. Sie öffnet die Anleitung als Webseite; mit `/pdf` dahinter öffnet sie ihr
PDF.

Die neueste Veröffentlichung ist die neueste der veröffentlichten Inhalte, die nicht
zurückgezogen ist. Eine Veröffentlichung aus einer
[Wartungslinie](/de/guide/releases/maintenance-lines) wird nie die neueste.

## Wenn der Dialog keine vollständige Adresse zeigt

Für vollständige Adressen und QR-Codes braucht der Server seine öffentliche Adresse. Fehlt sie,
zeigt der Dialog nur die Pfade und sagt das; bitten Sie Ihre Administration, sie einzustellen.

Wer die Adressen öffnen darf, ist eine Einstellung des Projekts: siehe
[Wer die Adressen öffnet](/de/guide/releases/address-access).
