Every manual is printed as a PDF: once per variant and language in a release, and on request in
the manual's preview. You don't set anything up for it; this page says what you get.

## Where to get one

- From a release: **Download** in the release's **Files**. See
  [Download the files](/guide/releases/download).
- Before a release: in the manual's preview, the PDF of one variant and language. See
  [Build a manual](/guide/manuals/build).

## Accessible for screen readers

Every PDF is a tagged PDF that meets PDF/UA-1, the standard for accessible PDF. A screen reader
finds the headings, the reading order, the tables' header cells, the lists and links, the
document's title and language, and a description of each image.

So the content must give what a screen reader needs: an alternative text for every image, a
heading for every section, no heading level skipped. When something is missing, the manual's
checks say so before you release. See [PDF accessibility](/guide/checks/pdf-accessibility).

## The same content, the same file

Rendering the same content with the same design again gives the same PDF, byte for byte. A
manual a release does not change keeps the file of the previous release.

## Fonts

The PDF uses the standard font unless the page design picks fonts of its own. The standard fonts
cover Latin, Cyrillic, Arabic and Hebrew script. A character no font can show is not printed as an
empty box: the manual's checks report it instead. See
[Fonts and cover images](/guide/releases/page-design-assets).

## How it looks

The page size, the title page, the colours, the running header and footer and more come from the
manual's page design. See [Page designs](/guide/releases/page-designs).
