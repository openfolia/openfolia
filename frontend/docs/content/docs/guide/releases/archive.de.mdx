title: 'Archivierte PDFs'
description: 'Eine Veröffentlichung behält ihre PDF-Dateien dauerhaft: Aus der Medienbibliothek lassen sie sich nicht löschen.'
articleId: 'guide.releases.archive'
---

Die PDF-Dateien einer Veröffentlichung belegen, was veröffentlicht wurde. Ist eine Datei fertig,
bleibt sie dauerhaft erhalten, auch wenn die Veröffentlichung zurückgezogen wird. Einzurichten ist
nichts.

## In der Medienbibliothek

Die Medienbibliothek bietet ein archiviertes PDF nie zum Löschen an:

- Der Filter **Unbenutzt** führt keines auf.
- Eine hochgeladene Datei mit genau demselben Inhalt wie ein archiviertes PDF lässt sich löschen:
  Ihr Upload verschwindet, das archivierte PDF bleibt.
- Eine Datei zu löschen, die eine Veröffentlichung behält, wird abgelehnt. Die Meldung sagt, dass
  sie behalten wurde und wo sie verwendet wird: **das archivierte PDF einer Veröffentlichung**.

## Speicher

Archivierte PDFs zählen mit den Medien zum Speicher des Projekts. Die Summe sehen
Administratoren unter **Verwaltung**, **System**, bei **Speicher**.
