---
title: 'Archived PDFs'
description: 'A release keeps its PDF files for good: they cannot be deleted from the media library.'
articleId: 'guide.releases.archive'
---

A release's PDF files are its record of what was published. Once a file is ready, it is kept for
good, also after the release is withdrawn. There is nothing to set up.

## In the media library

The media library never offers an archived PDF for deletion:

- The **Unused** filter never lists one.
- An uploaded file with exactly the same content as an archived PDF can be deleted: its upload
  goes, the archived PDF stays.
- Deleting a file a release keeps is refused. The message says it was kept, and where it is used:
  **a release’s archived PDF**.

## Storage

Archived PDFs count towards the project's storage, with the media. Administrators see the total
under **Admin**, **System**, in **Storage**.
