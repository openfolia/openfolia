---
title: 'Veröffentlichungen und PDFs'
description: 'Eine Veröffentlichung erstellen, ihre Dateien, Seitengestaltungen und dauerhafte Adressen.'
articleId: 'guide.releases'
---

Erstellen Sie eine Veröffentlichung für eine Produktversion, verfolgen und laden Sie ihre
PDF-Dateien herunter, legen Sie fest, wie sie aussehen, und geben Sie Lesern Adressen und QR-Codes,
die dauerhaft funktionieren.

Eine Veröffentlichung hält alle Inhalte in einem Commit fest: die Module, Handbücher,
Einstellungen, Seitengestaltungen und Begriffe. Siehe
[Fast alles ist Inhalt](/de/guide/getting-started/content).
