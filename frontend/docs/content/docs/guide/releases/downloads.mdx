The download centre lists every file a release offers for download, in one place: the files
attached in modules (a datasheet, a ZIP of examples) and the manuals’ PDFs. Each product’s files
are shown as its latest release holds them. Nothing is uploaded here: attach a file in a module
(see [Attachments](/guide/writing/attachments)) and cut a release, and it is listed.

## Find a file

1. Choose **Releases** in the sidebar, then the **Downloads** tab.
2. Narrow the list with **Product**, **Language** and **Kind** (**Attachment** or **Manual
   (PDF)**), or type words in **Search downloads**: the name, the description, the file name or
   the module’s title.
3. Choose **Download** in a row to save the current file.

Each row names the file, the module it is attached in or the manual’s variant, the product, the
product version of the release it is from and its size. A manual’s PDF is listed once it is
rendered.

## A file’s versions

Choose a row to open its versions beside the list, newest first. A file gets a new version only
when it changes: a release that holds the same file again adds none.

Each version shows:

- its state: **Current** (in the product’s latest release), **Superseded** (a later release
  holds another file) or **Withdrawn** (only in withdrawn releases);
- the product version and date of the release it came with;
- its SHA-256 checksum, to check a downloaded copy (the whole checksum shows when you point at
  it);
- the release’s notes and, when it changed, the file’s description.

Choose **Download** under a version to save that version.

## What you see

Only what you may read is listed: an attachment in a module above your audience is not in the
list, not in the count and has no versions for you. A manual’s PDF is listed for whoever may read
the whole manual in that language.

The versions come from the releases of the product’s main line, at most the latest 500; the
panel says so when there are more.
A file the product’s latest release no longer holds is not listed and has no versions.
