---
title: 'A revision whose branch is missing'
description: 'What you see when a revision can no longer be read, and what you can do.'
articleId: 'guide.review.missing-branch'
---

Each revision keeps its changes on a branch of its own in the content repository. If that branch
is gone, for example because the repository was restored from an older copy or the branch was
deleted outside the editor, the revision can no longer be read.

## What you see

- The revision menu at the top names it with **branch missing**, for example **Update the battery
  instructions (Draft, branch missing)**.
- With the revision chosen, the screens that read it show one message in place of their content:
  **This revision’s branch is missing from the content repository.**

The sidebar and the revision menu keep working. Nothing brings the branch back by itself, and no
change in it can be saved.

## What to do

- **Leave revision** goes back to the published content.
- **Abandon revision** closes it for good. It is offered to the revision's author and to an
  administrator. The message offers **Undo** for a few seconds.

If the changes matter, ask an administrator whether the branch can be restored from a backup of the
content repository before you abandon the revision.
