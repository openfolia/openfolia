title: 'Prüfung und Freigabe'
description: 'Überarbeitungen, Prüfung, Freigabe und Kommentare.'
articleId: 'guide.review'
---

Jede Änderung kommt über eine Prüfung in die veröffentlichten Inhalte: Jemand liest sie,
kommentiert, gibt sie frei, und eine Veröffentlicherin oder ein Veröffentlicher führt sie zusammen.
