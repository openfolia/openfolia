**Prüfung** in der Seitenleiste listet die Überarbeitungen nach ihrem Stand. Wählen Sie eine, um in
der Mitte ihre Änderungen und rechts ihre Freigaben zu sehen.

![Die Prüfseite: links die Liste, in der Mitte die Änderungen, rechts die Freigaben](/images/guide/de/review-list.webp)

## Wählen, was die Liste zeigt

Wählen Sie oben rechts eine von drei Möglichkeiten:

- **Wartend**: eingereicht, wartet auf Prüfung oder eine Abzeichnung. Der Seitentitel lautet **Warten
  auf Prüfung**.
- **Freigegeben**: freigegeben, wartet darauf, zusammengeführt zu werden: **Freigegeben, warten auf
  Zusammenführung**.
- **Entwürfe**: noch nicht eingereicht.

Die Zahl daneben sagt, wie viele Überarbeitungen jeweils darin sind, so verdeckt ein leeres
**Wartend** keinen Entwurf. Sie sehen nur Überarbeitungen, die Sie lesen dürfen.

## Eine Zeile lesen

Jede Zeile zeigt den Titel der Überarbeitung, wer sie begonnen hat, wann sie zuletzt geändert wurde,
und ihren Stand, etwa **In Prüfung**. **Mitwirkende Person** kennzeichnet eine Überarbeitung von jemandem,
dessen Rolle schreiben, aber weder prüfen noch abzeichnen darf.

Unter dem Titel der gewählten Überarbeitung fasst eine Zeile sie zusammen, etwa **1 geändertes
Element · Englisch · verglichen mit main**, daneben die Prüfungen: blockierende Probleme und
Warnungen. Wählen Sie sie, um [die Prüfungen](/de/guide/checks/run-checks) zu öffnen.

## Blättern

Die Liste zeigt 20 Überarbeitungen auf einmal. **Zeilen pro Seite** ändert das, **Zurück** und
**Weiter** blättern. Die Adresse behält Filter, Seite und gewählte Überarbeitung, so öffnet ein
Link darauf dieselbe Ansicht.

Auf einem schmalen Bildschirm zeigt die Seite einen Teil auf einmal. Wechseln Sie mit
**Überarbeitungen**, **Änderungen** und **Freigaben** darüber.
