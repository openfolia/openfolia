---
title: 'Eine Überarbeitung ohne Branch'
description: 'Was Sie sehen, wenn sich eine Überarbeitung nicht mehr lesen lässt, und was Sie tun können.'
articleId: 'guide.review.missing-branch'
---

Jede Überarbeitung hält ihre Änderungen in einem eigenen Branch im Inhalts-Repository. Fehlt dieser
Branch, etwa weil das Repository aus einer älteren Kopie wiederhergestellt oder der Branch
außerhalb des Editors gelöscht wurde, lässt sich die Überarbeitung nicht mehr lesen.

## Was Sie sehen

- Das Überarbeitungsmenü oben nennt sie mit **Branch fehlt**, etwa **Batterieanleitung
  aktualisieren (Entwurf, Branch fehlt)**.
- Ist die Überarbeitung gewählt, zeigen die Bildschirme, die sie lesen, statt ihres Inhalts eine
  Meldung: **Der Branch dieser Überarbeitung fehlt im Inhalts-Repository.**

Seitenleiste und Überarbeitungsmenü funktionieren weiter. Nichts holt den Branch von selbst zurück,
und keine Änderung darin lässt sich speichern.

## Was Sie tun können

- **Überarbeitung verlassen** führt zurück zu den veröffentlichten Inhalten.
- **Überarbeitung verwerfen** schließt sie endgültig. Das wird dem Autor der Überarbeitung und
  Administratoren angeboten. Die Meldung bietet einige Sekunden lang **Rückgängig** an.

Sind die Änderungen wichtig, fragen Sie eine Administratorin oder einen Administrator, ob sich der
Branch aus einer Sicherung des Inhalts-Repositorys wiederherstellen lässt, bevor Sie die
Überarbeitung verwerfen.
