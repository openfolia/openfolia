## Blöcke

| Block                       | Wofür                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Text**                    | Ein einfacher Absatz.                                                                                              |
| **Überschrift 1** bis **3** | Abschnitte des Moduls. Eine **Überschrift 2** steht in einer **Überschrift 1**, eine **Überschrift 3** in einer 2. |
| **Aufzählung**              | Punkte ohne Reihenfolge.                                                                                           |
| **Nummerierte Liste**       | Punkte in einer Reihenfolge.                                                                                       |
| **Tabelle**                 | Zeilen und Spalten, mit verbundenen Zellen und Ausrichtung.                                                        |
| **Handlungsanweisung**      | Ein Titel und nummerierte Schritte; ein Schritt kann ein **Ergebnis des Schritts** haben: wozu er führt.           |
| **Sicherheitshinweis**      | Eine Gefährdung und wie man sie vermeidet, in einer Stufe (Gefahr, Warnung, Vorsicht), mit Sicherheitssymbolen.    |
| **Hinweis**                 | Ein Hinweis, ein Tipp oder etwas Wichtiges, vom Text abgesetzt.                                                    |
| **FAQ-Eintrag**             | Eine Frage und ihre Antwort.                                                                                       |
| **Bild**                    | Ein Bild aus der Medienbibliothek oder hochgeladen, mit Alternativtext und Positionsnummern.                       |
| **Anhang**                  | Eine Datei zum Herunterladen: ein ZIP, ein JSON-Beispiel, ein Datenblatt.                                          |
| **Codeblock**               | Vorformatierter Text, etwa eine Konfigurationsdatei.                                                               |
| **Variantenblock**          | Text nur für einige Varianten. Siehe [Text für einige Varianten](/de/guide/variants/variant-blocks).               |
| **Modulverweis**            | Ein anderes Modul, hier eingefügt. Siehe [Ein Modul wiederverwenden](/de/guide/writing/reuse-modules).             |
| **Textbaustein**            | Wiederverwendbare Formulierung, als Referenz oder als Kopie. Siehe [Textbausteine](/de/guide/writing/snippets).    |
| **Seitenumbruch**           | Eine neue Seite im PDF.                                                                                            |

## In einer Textzeile

| Element                         | Wofür                                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| **Link**                        | Eine Web- oder E-Mail-Adresse.                                                                |
| **Querverweis**                 | Ein Link auf einen Abschnitt, eine Abbildung, Tabelle, Handlungsanweisung oder einen Schritt. |
| **Textattribut**                | Ein Wert, der je Anleitung eingesetzt wird, etwa ein Produktname.                             |
| **Platzhalter**                 | Daten der Anleitung, etwa die Produktversion.                                                 |
| **Tastenkombination**           | Tasten als Tastenkappen, etwa <kbd>Strg</kbd> <kbd>S</kbd>.                                   |
| **Verweis auf Positionsnummer** | Die Nummer einer Positionsnummer in einem Bild dieses Moduls.                                 |
