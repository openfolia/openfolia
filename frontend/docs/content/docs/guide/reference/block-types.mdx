The **Insert** menu and the slash menu (<kbd>/</kbd>) add these. See
[Insert blocks](/guide/writing/blocks).

## Blocks

| Block                  | What it is for                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| **Text**               | A plain paragraph.                                                                               |
| **Heading 1** to **3** | Sections of the module. A **Heading 2** goes inside a **Heading 1**, a **Heading 3** inside a 2. |
| **Bulleted list**      | Items in no order.                                                                               |
| **Numbered list**      | Items in order.                                                                                  |
| **Table**              | Rows and columns, with merged cells and alignment.                                               |
| **Procedure**          | A title and numbered steps; a step can have a **Step result**: what it leads to.                 |
| **Safety notice**      | A hazard and how to avoid it, at a level (danger, warning, caution), with safety symbols.        |
| **Note**               | A note, tip or important remark set off from the text.                                           |
| **FAQ entry**          | A question and its answer.                                                                       |
| **Image**              | A picture from the media library or an upload, with its alternative text and callouts.           |
| **Attachment**         | A file readers download: a ZIP, a JSON sample, a datasheet.                                      |
| **Code block**         | Preformatted text, such as a configuration file.                                                 |
| **Variant block**      | Text for some variants only. See [Text for some variants](/guide/variants/variant-blocks).       |
| **Module reference**   | Another module, included here. See [Reuse a module](/guide/writing/reuse-modules).               |
| **Snippet**            | Reusable wording, by reference or as a copy. See [Snippets](/guide/writing/snippets).            |
| **Page break**         | A new page in the PDF.                                                                           |

## Inside a line of text

| Item                  | What it is for                                                |
| --------------------- | ------------------------------------------------------------- |
| **Link**              | A web or email address.                                       |
| **Cross-reference**   | A link to a section, figure, table, procedure or step.        |
| **Text attribute**    | A value filled in per manual, such as a product name.         |
| **Placeholder**       | Manual data, such as the product version.                     |
| **Key combination**   | Keys shown as key caps, such as <kbd>Ctrl</kbd> <kbd>S</kbd>. |
| **Callout reference** | The number of a callout on one of this module's images.       |
