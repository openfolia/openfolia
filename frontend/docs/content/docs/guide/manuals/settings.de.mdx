Die Einstellungen einer Anleitung sagen, wofür sie erstellt wird. Die Karte **Einstellungen** im
Editor fasst sie zusammen: die Zielgruppe, die Zahl der Varianten-Builds, das Titelbild und wie
viele Textattribute gesetzt sind. Änderungen werden sofort in Ihrer Überarbeitung im Entwurf
gespeichert.

1. Öffnen Sie die Anleitung unter **Anleitungen**.
2. Wählen Sie **Einstellungen bearbeiten** in der Karte **Einstellungen**. Ohne Überarbeitung im
   Entwurf zeigt **Einstellungen anzeigen** sie schreibgeschützt.

![Die Einstellungen: Titel, Zielgruppe, Seitengestaltung, Titelbild und Varianten-Builds](/images/guide/de/manual-settings.webp)

## Titel

Der Titel der Anleitung steht auf der Titelseite ihres PDFs, in der Kopfzeile und im Portal.
Geben Sie ihn in der Ausgangssprache ein. Unter **Weitere Sprachen** geben Sie ihm in jeder
Übersetzungssprache einen eigenen Titel; ein leeres Feld übernimmt den Titel der Ausgangssprache.
Der Titel einer Gruppe in der Gliederung hat dieselben Felder dort, wo Sie die Gruppe umbenennen.

Jedes PDF und jede Portalseite zeigt den Titel in ihrer Sprache. Übersetzer erhalten die Titel
auch mit einem Delta-Export: siehe [Texte von Seitengestaltung, Anleitung und Bezeichnungen](/de/guide/translations/special-texts).

## Zielgruppe

Wählen Sie, für wen die Anleitung ist. **Nicht gesetzt (jede Zielgruppe)** nimmt jedes Modul auf.
Module für eine engere Zielgruppe werden weggelassen: siehe
[Zielgruppen](/de/guide/manuals/audiences).

## Seitengestaltung und Titelbild

Mit der **Seitengestaltung** wird das PDF gedruckt; **Projektstandard** verwendet die, die Ihr Admin
festgelegt hat. Siehe [Seitengestaltungen](/de/guide/releases/page-designs). Auch das **Titelbild**
setzen Sie hier: siehe [Schriften und Titelbilder](/de/guide/releases/page-design-assets).

## Varianten-Builds

Jeder Varianten-Build ist eine Kombination von Variantenmerkmalen, etwa **Model** **Small**. Jeder
wird als eigene Anleitung erstellt und geprüft.

1. Wählen Sie **Varianten-Build hinzufügen**.
2. Wählen Sie für jedes Merkmal einen Wert, oder lassen Sie es **Nicht gesetzt**.
3. Wählen Sie **Hinzufügen**.

Der Stift bearbeitet einen Build, der Papierkorb entfernt ihn; die Meldung bietet **Rückgängig**
an. Eine Anleitung behält mindestens einen Build.

## Textattribute

Ein Textattribut, etwa **Product name**, ist ein Wert, der in den Text eingesetzt wird, wo ein
Modul ihn verwendet.

1. Geben Sie unter **Textattribute** den Wert ein und wählen Sie **Wert setzen**.
2. Für einen Wert, der je Variante anders ist, wählen Sie daneben **Nur für einige Varianten…** und
   wählen Sie die Varianten. Dann **Wert hinzufügen** für den nächsten.

Der erste Wert, dessen Varianten passen, wird verwendet. Ein Wert nach einem für **Jede Variante**
wird nie verwendet, und die Einstellungen sagen das. Das Kreuz neben einem Wert entfernt ihn.
