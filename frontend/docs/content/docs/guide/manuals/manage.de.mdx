All das geschieht in einer Überarbeitung im Entwurf und wird mit ihr geprüft. Veröffentlichte
Inhalte behalten die Anleitung, wie sie ist, bis die Überarbeitung zusammengeführt ist.

![Das Aktionsmenü einer Anleitung: Prüfungen ausführen, Verlauf, Umbenennen, Duplizieren, Als veraltet kennzeichnen… und Anleitung löschen](/images/guide/de/manual-menu.webp)

Öffnen Sie die Anleitung unter **Anleitungen** und wählen Sie oben rechts **…** (**Aktionen für** die
Anleitung).

## Eine Anleitung anlegen

Wählen Sie oben den Titel der Anleitung, dann **Neue Anleitung**. Siehe
[Eine Anleitung zusammenstellen](/de/guide/manuals/build). Um mit der Gliederung einer anderen
Anleitung zu beginnen, haken Sie **Mit einer Kopie einer anderen Anleitung beginnen** an und wählen
Sie unter **Zu kopierende Anleitung** die Anleitung.

## Eine Anleitung duplizieren

1. Wählen Sie **Duplizieren**. Der Dialog **Neue Anleitung** öffnet sich mit **Kopie von** der
   Anleitung als Titel und der zu kopierenden Anleitung gewählt.
2. Ändern Sie den **Titel**: Die ID der Anleitung wird daraus gebildet.
3. Wählen Sie **Anlegen und öffnen**.

## Eine Anleitung umbenennen

1. Wählen Sie **Umbenennen**. Der Titel oben wird zu einem Feld.
2. Geben Sie den neuen Titel ein und drücken Sie <kbd>Eingabe</kbd>, oder verlassen Sie das Feld.
   <kbd>Esc</kbd> bricht ab.

Die ID der Anleitung bleibt, wie sie ist.

## Eine Anleitung als veraltet kennzeichnen

Eine veraltete Anleitung bleibt lesbar und kann weiter veröffentlicht werden. Sie gilt als veraltet,
sobald die Überarbeitung zusammengeführt ist.

1. Wählen Sie **Als veraltet kennzeichnen…**.
2. Geben Sie einen **Grund** ein und bei Bedarf die Anleitung unter **Ersetzt durch (optional)**.
3. Wählen Sie **Als veraltet kennzeichnen**.

Die Meldung bietet **Rückgängig** an. Später nimmt **Kennzeichnung als veraltet aufheben** im
selben Menü es zurück.

## Eine Anleitung löschen

Wählen Sie **Anleitung löschen**. Sie wird sofort gelöscht, in dieser Überarbeitung, und der Editor
wechselt zur nächsten Anleitung. Die Meldung bietet **Rückgängig** an, solange die Überarbeitung ein
Entwurf ist.

Eine gelöschte Anleitung behält ihren Verlauf. Wählen Sie oben den Titel der Anleitung, schalten Sie
**Gelöschte anzeigen** ein und wählen Sie sie: Ihr Verlauf öffnet sich, wo Sie eine Version
wiederherstellen. Siehe [Der Verlauf einer Anleitung](/de/guide/manuals/history).
