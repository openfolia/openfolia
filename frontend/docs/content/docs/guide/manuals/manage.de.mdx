All das geschieht in einer Überarbeitung im Entwurf und wird mit ihr geprüft. Veröffentlichte
Inhalte behalten das Handbuch, wie es ist, bis die Überarbeitung zusammengeführt ist.

![Das Aktionsmenü eines Handbuchs: Prüfungen ausführen, Verlauf, Umbenennen, Duplizieren, Als veraltet kennzeichnen… und Handbuch löschen](/images/guide/de/manual-menu.webp)

Öffnen Sie das Handbuch unter **Handbücher** und wählen Sie oben rechts **…** (**Aktionen für** das
Handbuch).

## Ein Handbuch anlegen

Wählen Sie oben den Titel des Handbuchs, dann **Neues Handbuch**. Siehe
[Ein Handbuch zusammenstellen](/de/guide/manuals/build). Um mit der Gliederung eines anderen
Handbuchs zu beginnen, haken Sie **Mit einer Kopie eines anderen Handbuchs beginnen** an und wählen
Sie unter **Zu kopierendes Handbuch** das Handbuch.

## Ein Handbuch duplizieren

1. Wählen Sie **Duplizieren**. Der Dialog **Neues Handbuch** öffnet sich mit **Kopie von** dem
   Handbuch als Titel und dem zu kopierenden Handbuch gewählt.
2. Ändern Sie den **Titel**: Die ID des Handbuchs wird daraus gebildet.
3. Wählen Sie **Anlegen und öffnen**.

## Ein Handbuch umbenennen

1. Wählen Sie **Umbenennen**. Der Titel oben wird zu einem Feld.
2. Geben Sie den neuen Titel ein und drücken Sie <kbd>Eingabe</kbd>, oder verlassen Sie das Feld.
   <kbd>Esc</kbd> bricht ab.

Die ID des Handbuchs bleibt, wie sie ist.

## Ein Handbuch als veraltet kennzeichnen

Ein veraltetes Handbuch bleibt lesbar und kann weiter veröffentlicht werden. Es gilt als veraltet,
sobald die Überarbeitung zusammengeführt ist.

1. Wählen Sie **Als veraltet kennzeichnen…**.
2. Geben Sie einen **Grund** ein und bei Bedarf das Handbuch unter **Ersetzt durch (optional)**.
3. Wählen Sie **Als veraltet kennzeichnen**.

Die Meldung bietet **Rückgängig** an. Später nimmt **Kennzeichnung als veraltet aufheben** im
selben Menü es zurück.

## Ein Handbuch löschen

Wählen Sie **Handbuch löschen**. Es wird sofort gelöscht, in dieser Überarbeitung, und der Editor
wechselt zum nächsten Handbuch. Die Meldung bietet **Rückgängig** an, solange die Überarbeitung ein
Entwurf ist.

Ein gelöschtes Handbuch behält seinen Verlauf. Wählen Sie oben den Titel des Handbuchs, schalten Sie
**Gelöschte anzeigen** ein und wählen Sie es: Sein Verlauf öffnet sich, wo Sie eine Version
wiederherstellen. Siehe [Der Verlauf eines Handbuchs](/de/guide/manuals/history).
