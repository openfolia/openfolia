Ein Sicherheitsblatt enthält die Sicherheitshinweise aus dem Handbuch eines Produkts, auf wenigen
kleinen Seiten. Sie stellen es nicht von Hand zusammen: Ein abgeleitetes Handbuch sammelt die
Module bestimmter Typen aus seinem Quellhandbuch, in dessen Reihenfolge, jedes einmal. Ändert sich
die Quelle, folgt das Blatt.

## Das Blatt anlegen

1. Wählen Sie **Handbücher** in der Seitenleiste, dann oben den Titel des Handbuchs, dann **Neues
   Handbuch**.
2. Geben Sie einen **Titel** ein, etwa „Sicherheitsblatt für das Servicepersonal“.
3. Wählen Sie unter **Art** **Aus einem anderen Handbuch abgeleitet**.
4. Wählen Sie das **Quellhandbuch**: das Handbuch, dessen Sicherheitsmodule es sammelt. Eine Quelle
   ist ein zusammengestelltes Handbuch für dieselbe oder eine weitere Zielgruppe.
5. Lassen Sie **Gesammelte Modultypen** leer, um die Typen zu sammeln, die Ihre Einstellungen als
   Sicherheitsinhalt markieren (in den Beispielinhalten **Safety**). Oder wählen Sie die Typen.
6. Wählen Sie **Anlegen und öffnen**.

![Der Dialog Neues Handbuch mit Aus einem anderen Handbuch abgeleitet](/images/guide/de/new-derived-manual.webp)

## Das Blatt lesen

Die Gliederung zeigt, was die Regel sammelt: etwa **3 Module, gesammelt aus Operating manual**.
Jedes gesammelte Modul behält die Variantenbedingungen, die es in der Quelle hat. Ein Abzeichen wie
**Nicht in Small** sagt, dass eine Variante es nicht bekommt.

![Ein Sicherheitsblatt: die gesammelten Module und daneben die Sammelregel](/images/guide/de/safety-leaflet.webp)

Zeilen ziehen oder hinzufügen können Sie hier nicht: Die **Sammelregel** rechts bestimmt die
Gliederung.

## Die Regel ändern

In der **Sammelregel**:

- **Quellhandbuch** und **Gesammelte Modultypen**: wie beim Anlegen.
- **Vorspann (vor den gesammelten Modulen)**: Wählen Sie **Hinzufügen**, um ein Modul an den Anfang
  zu setzen, etwa eine Einleitung. Der Nachspann funktioniert genauso, nach ihnen.
- **Ausgelassen**: Module, die das Blatt nicht sammelt. Um eines auszulassen, wählen Sie das
  durchgestrichene Auge am Ende seiner Zeile (oder wählen Sie die Zeile und drücken Sie
  <kbd>Entf</kbd>). **Wieder aufnehmen** holt es zurück.

Die Prüfungen der Regel stehen daneben. **Blockierend:** heißt, das Blatt lässt sich nicht
veröffentlichen, bis das behoben ist.

## Stattdessen die Sicherheitshinweise sammeln

Ein Blatt kann statt ganzer Module die Sicherheitshinweise der Module der Quelle enthalten: jede
Gefahr, Warnung, Vorsicht und jeden Hinweis, ohne den Text darum herum.

1. Wählen Sie in der **Sammelregel** unter **Was es sammelt** **Sicherheitshinweise der Module der
   Quelle**. (**Ganze Module der Typen unten** ist die Voreinstellung.)
2. Wählen Sie unter **Hinweise gruppieren** **Nach Quellmodul** für eine Gruppe je Modul, oder
   **Nach Gefahrenstufe** für eine Überschrift je Stufe, die schwerste zuerst.
3. Nehmen Sie unter **Gesammelte Gefahrenstufen** den Haken bei einer Stufe weg, um ihre Hinweise
   auszulassen. Nach Gefahrenstufe gruppiert, ziehen Sie eine Stufe, um die Reihenfolge der Gruppen
   zu ändern.
4. Wählen Sie unter **Modultypen, die nach Hinweisen durchsucht werden** die Typen, oder lassen Sie
   **Alle Typen**: Jedes Modul der Quelle wird durchsucht, und die Module, auf die es verweist.

![Die Sammelregel auf Sicherheitshinweise gestellt, nach Gefahrenstufe gruppiert, mit den gesammelten Stufen](/images/guide/de/manual-leaflet-notices.webp)

Die Gliederung listet dann die Module mit Hinweisen auf, in der Reihenfolge der Quelle: etwa **3
Module mit Hinweisen, gesammelt aus Operating manual, nach Gefahrenstufe gruppiert**. Jeder Hinweis
behält die Variantenbedingungen, die er in der Quelle hat. Einen Hinweis, den die Regel auslässt
(ein ausgelassenes Modul, ein nicht durchsuchter Typ, eine nicht gesammelte Stufe), melden die
Prüfungen als **Sicherheitshinweis ausgelassen**, damit Sie bestätigen können, dass das gewollt ist.

## Drucken

Das Blatt ist ein Handbuch wie jedes andere: Sehen Sie es in der Vorschau an, prüfen und
veröffentlichen Sie es. Für kleine Seiten wählen Sie in seiner Karte **Einstellungen** unter
**Seitengestaltung** eine Gestaltung für Faltblätter: A5 hochkant, kleine Schrift, die Module
fortlaufend. Seitengestaltungen legt Ihr Admin unter **Verwaltung**, **Seitengestaltung** an.
