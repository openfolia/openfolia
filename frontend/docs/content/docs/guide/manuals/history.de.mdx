title: 'Der Verlauf einer Anleitung'
description: 'Alle Versionen einer Anleitung sehen, Details und Gliederung zwischen zwei vergleichen und eine ältere wiederherstellen.'

---

Jeder Speicherpunkt einer Anleitung macht eine neue Version: ein Modul hinzugefügt oder entfernt,
die Reihenfolge geändert, eine Einstellung geändert. Ihr Verlauf funktioniert wie der eines
Moduls.

## Den Verlauf öffnen

1. Öffnen Sie die Anleitung unter **Anleitungen**.
2. Wählen Sie oben rechts **…**, dann **Verlauf**.

![Der Verlauf einer Anleitung: links die Versionen, rechts, was Version 4 an der Gliederung geändert hat](/images/guide/de/manual-history.webp)

Die Versionen stehen mit der neuesten zuerst, jede mit dem, der sie wann und in welcher
Überarbeitung angelegt hat. **Veröffentlicht** markiert eine Version in einer Veröffentlichung.

## Zwei Versionen vergleichen

Wählen Sie eine Version: Sie wird mit der davor verglichen. Der Vergleich zeigt die Details der
Anleitung und ihre Gliederung: hinzugefügte, entfernte oder verschobene Einträge. Unveränderte
Einträge sind in einer Zeile wie **4 unveränderte Einträge · zeigen** eingeklappt: Wählen Sie sie,
um sie zu öffnen. Um mit einer anderen Version
zu vergleichen, wählen Sie darunter **Mit … vergleichen**.

## Eine ältere Version wiederherstellen

1. Wählen Sie oben eine Überarbeitung im Entwurf.
2. Wählen Sie im Verlauf die Version, die Sie zurückholen möchten.
3. Wählen Sie **… als Entwurf wiederherstellen**, etwa **Version 3 als Entwurf wiederherstellen**.

Die Anleitung lautet nun wie diese Version, in Ihrer Überarbeitung. Die Meldung bietet
**Rückgängig** an.

Auch eine gelöschte Anleitung hat einen Verlauf: Wählen Sie oben den Titel der Anleitung, schalten
Sie **Gelöschte anzeigen** ein und wählen Sie sie. Siehe [Eine Anleitung duplizieren, umbenennen, als
veraltet kennzeichnen oder löschen](/de/guide/manuals/manage).
