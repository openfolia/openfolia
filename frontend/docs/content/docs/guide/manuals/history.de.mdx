Jeder Speicherpunkt eines Handbuchs macht eine neue Version: ein Modul hinzugefügt oder entfernt,
die Reihenfolge geändert, eine Einstellung geändert. Sein Verlauf funktioniert wie der eines
Moduls.

## Den Verlauf öffnen

1. Öffnen Sie das Handbuch unter **Handbücher**.
2. Wählen Sie oben rechts **…**, dann **Verlauf**.

![Der Verlauf eines Handbuchs: links die Versionen, rechts, was Version 4 an der Gliederung geändert hat](/images/guide/de/manual-history.webp)

Die Versionen stehen mit der neuesten zuerst, jede mit dem, der sie wann und in welcher
Überarbeitung angelegt hat. **Veröffentlicht** markiert eine Version in einer Veröffentlichung.

## Zwei Versionen vergleichen

Wählen Sie eine Version: Sie wird mit der davor verglichen. Der Vergleich zeigt die Details des
Handbuchs und seine Gliederung: hinzugefügte, entfernte oder verschobene Einträge. Unveränderte
Einträge sind in einer Zeile wie **4 unveränderte Einträge · zeigen** eingeklappt: Wählen Sie sie,
um sie zu öffnen. Um mit einer anderen Version
zu vergleichen, wählen Sie darunter **Mit … vergleichen**.

## Eine ältere Version wiederherstellen

1. Wählen Sie oben eine Überarbeitung im Entwurf.
2. Wählen Sie im Verlauf die Version, die Sie zurückholen möchten.
3. Wählen Sie **… als Entwurf wiederherstellen**, etwa **Version 3 als Entwurf wiederherstellen**.

Das Handbuch lautet nun wie diese Version, in Ihrer Überarbeitung. Die Meldung bietet
**Rückgängig** an.

Auch ein gelöschtes Handbuch hat einen Verlauf: Wählen Sie oben den Titel des Handbuchs, schalten
Sie **Gelöschte anzeigen** ein und wählen Sie es. Siehe [Ein Handbuch duplizieren, umbenennen, als
veraltet kennzeichnen oder löschen](/de/guide/manuals/manage).
