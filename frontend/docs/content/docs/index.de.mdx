---

OpenFolia ist eine Headless-Dokumentationsplattform. Inhalte werden einmal als kleine Module
geschrieben und dann zu Handbüchern für jede Produktvariante und Sprache zusammengestellt.
Autorinnen und Autoren arbeiten in einem Web-Editor an Entwürfen, die vor der Freigabe geprüft
werden. Jede Veröffentlichung wird über eine JSON:API ausgeliefert und als PDF und HTML erzeugt, sodass
derselbe Inhalt Druck, Portal und andere Systeme erreicht.

Fast alles darin ist Inhalt: die Module, aber auch die Handbücher, die Projekteinstellungen, die
Seitengestaltungen und die Begriffe, alle in Git versioniert und über die Prüfung geändert. Siehe
[Fast alles ist Inhalt](/de/guide/getting-started/content).
