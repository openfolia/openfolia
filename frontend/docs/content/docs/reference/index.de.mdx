---
title: 'Referenz'
description: 'Kataloge, die aus dem Quellcode erzeugt werden.'
---

Diese Seiten werden bei jedem Build aus dem Repository erzeugt und können so nicht vom Code ihrer
Version abweichen. Die Berechtigungen und die Fehlercodes sind auf Deutsch, ihre Texte die des
Editors. Die anderen Seiten sind auf Englisch, weil es ihre Quelle im Code ist:

| Seite                                                | Erzeugt aus                                                                     |
| ---------------------------------------------------- | ------------------------------------------------------------------------------- |
| [Fehlercodes](/de/reference/errors)                  | `backend/api/error-codes.yaml`, abgeglichen mit jedem Code, den die API auslöst |
| [Berechtigungen](/de/reference/permissions)          | der Berechtigungsliste der API und der Berechtigung jeder Route                 |
| [Einstellungen](/de/reference/settings)              | `.env.example` und seinen Kommentaren                                           |
| [Projektkonfiguration](/de/reference/project-config) | dem Schema der `openfolia.yaml` im Inhaltsmodell                                |
| [Importformat](/de/reference/import-format)          | `import-format.schema.json`                                                     |
| [MCP-Werkzeuge](/de/reference/mcp-tools)             | den Werkzeugdefinitionen des MCP-Servers                                        |
