Es gibt zwei Wege: Sie nutzen ein OpenFolia, das für Sie betrieben wird, oder Sie betreiben es
selbst. Beide haben denselben Editor, dieselbe API und dieselbe Benutzeranleitung.

## Ihr OpenFolia nutzen

Ein gehostetes OpenFolia hat eine Adresse wie `https://<team>.openfolia.com`. Sonst nennt Ihr Admin
Ihnen die Adresse. Sie installieren nichts.

### Anmelden

1. Öffnen Sie Ihre Adresse im Browser.
2. Melden Sie sich so an, wie die Seite es anbietet: mit dem Konto Ihrer Organisation, einem
   Passwort oder einem Code per E-Mail. Welche Wege es gibt, entscheidet Ihr Admin. Siehe
   [An- und abmelden](/de/guide/getting-started/sign-in).
3. Sie sehen **Inhalte**. [Orientierung](/de/guide/getting-started/find-your-way) und
   [Die erste Änderung](/de/guide/getting-started/first-edit) zeigen, wie es weitergeht.

### Ein Token erstellen

Ein Programm, etwa eine Pipeline, ein Portal-Build oder ein Agent, ruft die API mit dem Token
eines Service-Accounts auf. Tokens gehören zu Service-Accounts, nie zu einer Person.

1. Jemand mit der Berechtigung `admin.roles` öffnet **Verwaltung**, dann **Service-Accounts**.
2. Er oder sie legt einen Service-Account mit einer Rolle an, die enthält, was das Programm braucht.
   Zum Lesen veröffentlichter Inhalte ist das nur `content.read`.
3. Er oder sie stellt ein Token dafür aus und kopiert es. Es wird nur einmal angezeigt.

[Service-Accounts und Tokens](/de/guide/admin/service-accounts) beschreibt jeden Schritt,
[Mit dem Token eines Service-Accounts authentifizieren](/de/guide/integrations/authentication),
wie Sie es senden.

### Die API aufrufen

Die API liegt unter Ihrer Adresse plus `/api`. Listen Sie die Anleitungen auf:

```sh
curl -s https://<team>.openfolia.com/api/manuals \
  -H 'Authorization: Bearer ccms_sat_…' \
  -H 'Accept: application/vnd.api+json'
```

Ihre interaktive Referenz liegt unter `/api/docs` derselben Adresse. Die
[Delivery API](/de/api/delivery) beschreibt die Routen, die ein Portal oder eine Integration
liest, die [API-Referenz](/de/api) jede Route.

### Einen Agenten anbinden

Mit dem [MCP-Server](/de/guides/mcp) durchsuchen und lesen KI-Assistenten und Agenten die
veröffentlichten Inhalte. Verbinden Sie einen Client mit der Adresse und `/mcp`
(`https://<team>.openfolia.com/mcp`) und dem MCP-Token, das Ihnen Ihr Anbieter oder Ihr Admin gibt.
Er liest nur.

## Selbst betreiben

Dieser Teil bringt OpenFolia lokal mit einem Beispiel-Inhaltsrepository zum Laufen. Für den
Betrieb auf einem Server siehe [Selbst betreiben](/de/self-hosting).

Oder lassen Sie Ihren Coding-Agenten es mit Ihnen installieren und starten:

<AgentInstall lang="de" />

### Voraussetzungen

- Docker mit Compose 2.24 oder neuer.
- Für die Arbeit am Code: Node 24 und pnpm 11.

### Die Container starten

Am schnellsten geht es mit der Container-Einrichtung in `deploy/` und den Beispielinhalten.
Legen Sie `deploy/.env` mit einem Postgres-Passwort an, bauen Sie die Images, legen Sie die
Beispielinhalte auf das Datenvolume und starten Sie:

```sh
cd deploy
printf 'POSTGRES_PASSWORD=%s\n' "$(openssl rand -hex 24)" >> .env
docker compose -f compose.yaml -f compose.build.yaml build
docker compose run --rm --no-deps api node docker/sample-content.mjs
docker compose up -d --wait
curl -s http://127.0.0.1:3000/health
```

Der Editor läuft unter `http://127.0.0.1:8080`, die API unter `http://127.0.0.1:3000`, ihre
interaktive Referenz unter `/docs`. [Selbst betreiben](/de/self-hosting) erklärt jeden Schritt.

### Der erste API-Aufruf

Jede Route außer `/health`, `/about` und der API-Referenz braucht ein Token. Erzeugen Sie das
Token eines Dienstkontos (es wird einmal ausgegeben) und listen Sie die Anleitungen der
Beispielinhalte auf:

```sh
docker compose exec api node dist/database/service-token.main.js <account> --role <role>
curl -s -H "Authorization: Bearer <token>" http://127.0.0.1:3000/manuals
```

Die [Delivery API](/de/api/delivery) beschreibt die Routen, die ein Portal oder eine Integration
liest.

### Ein Leseportal

Aus denselben Inhalten lässt sich ein Portal erstellen: eine statische Website, die Ihre Leser
durchsuchen und lesen, neben dem Editor, den PDF-Dateien und der API. Legen Sie bei laufender API
das Token eines Service-Accounts nur mit `content.read` an (siehe
[Erstellen und Vorschau](/de/guide/portal/build)). Erstellen Sie das Portal in einem Checkout des
Repositorys und sehen Sie es sich an:

```sh
CCMS_PORTAL_API_URL=http://127.0.0.1:3000 \
CCMS_PORTAL_TOKEN="<token>" \
CCMS_PORTAL_AUDIENCE=public \
pnpm nx run portal:site
npx serve frontend/portal/dist -l 4330   # dann http://localhost:4330 öffnen
```

Das [Portal-Kapitel](/de/guide/portal) erklärt die Einstellungen, das Branding und die
Bereitstellung.

### Aus dem Quellcode

```sh
pnpm install
docker compose up -d          # Postgres und S3-kompatibler Speicher für die Entwicklung
pnpm nx run api:setup-local   # ein Beispiel-Inhaltsrepository und lokale Einstellungen
pnpm nx run api:serve-local   # die API auf diesen Beispielinhalten
```
