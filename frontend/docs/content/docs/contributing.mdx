OpenFolia is open source under the AGPL-3.0. How to set up the repository, the checks a change
must pass, and how pull requests are reviewed are in `CONTRIBUTING.md` at the root of the
repository; the code of conduct is `CODE_OF_CONDUCT.md`, and how to report a security issue is
`SECURITY.md`.

## These docs

The site lives in the repository, in `frontend/docs`, so a change to the API updates its docs in
the same pull request. The hand-written pages are MDX in `frontend/docs/content/docs`
(`page.mdx` in English, `page.de.mdx` in German). The reference pages are generated on every
build and never edited by hand.
