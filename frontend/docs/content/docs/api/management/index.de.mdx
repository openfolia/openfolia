---
title: 'Management API'
description: 'Jede Route des Servers, die nicht zur Delivery API gehört.'
---

Die Management API umfasst alles Weitere, was der Server tut: Überarbeitungen und ihre Prüfung,
Sperren und Arbeitskopien, Veröffentlichungen und ihre Ausgaben, Übersetzungen, Importe, Kommentare,
Prüfungen, Benutzer, Rollen und Dienstkonten, Branding, Webhooks, Sicherungen, das Audit-Log.

Jede Operation steht einmal: die lesenden Routen über freigegebene Inhalte sind in der
[Delivery API](/de/api/delivery), und das vollständige Dokument des Servers (`/api/openapi.json`
auf Ihrer Instanz) enthält beide. Anfragen gehen an die Adresse Ihrer Instanz plus `/api`:
`https://<team>.openfolia.com/api` für ein gehostetes Team, die Adresse Ihres Editors plus `/api`,
wenn Sie es selbst betreiben, mit dem Token eines Service-Accounts
([Die Adresse Ihrer API und ein Token](/de/api#die-adresse-ihrer-api-und-ein-token)). `/api/docs`
auf Ihrer Instanz ist deren eigene interaktive Referenz, in der Sie Anfragen senden können. Die Seiten der einzelnen Operationen sind auf Englisch.
