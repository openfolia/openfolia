## Your API's address and a token

Every request goes to your instance's address plus `/api`:

- **Hosted OpenFolia:** `https://<team>.openfolia.com/api`, with your team's name.
- **Self-hosted:** your editor's address plus `/api`, such as `https://openfolia.example.com/api`.

Each operation's page has a field for your host above the operation; the code samples use it,
and your browser keeps it for the other pages. This site sends no requests itself: copy a sample
and run it, or open `/api/docs` on your instance (`https://<team>.openfolia.com/api/docs`), its
own interactive reference, to try requests there.

A request needs a token: `Authorization: Bearer <token>`. Issue one for a service account under
**Admin › Service accounts** ([Service accounts and tokens](/guide/admin/service-accounts)); this
needs the **admin.roles** permission, so if you don't hold it, ask an admin for a token.

## Conventions

- **JSON:API:** responses are `application/vnd.api+json` documents. Resources are
  `{ type, id, attributes, relationships, meta }`; `attributes` hold stored data and `meta` what
  the server derives from it.
- **Deactivated people:** where the reference lists `meta.people`, an answer that names people
  (authors, approvers, commenters) says whether each is deactivated: `[{ "id", "deactivated" }]`,
  users only. It is the state when the answer was made, also on answers you read at a commit.
- **Lists are paged:** `page[number]` and `page[size]`, with `meta.page` and `links`. Query
  parameters a route does not document are refused with 400 `unsupported-parameter`.
- **Errors** are `{ errors: [{ status, title, detail, code, source?, meta? }] }` on every route,
  with a stable `code`: see [error codes](/reference/errors).
- **Authentication:** `Authorization: Bearer <token>`, a service account's token. Each route
  needs a [permission](/reference/permissions).
- **Refs:** content routes read at `?ref=` (a branch, tag or commit), by default the server's
  default ref; every answer names the commit it read in `X-Ccms-Commit`.
