---
title: 'Delivery API'
description: 'Read released content: for portals, apps, integrations and RAG pipelines.'
---

The Delivery API is what someone building their own viewer, portal or integration needs: the
read routes over released content, and nothing about drafts. A consumer's token belongs to a
service account whose role holds only `content.read`.

Each operation has a page in the sidebar, with its parameters, responses, schemas and code
samples for your instance's address: `https://<team>.openfolia.com/api` for a hosted team, your
editor's address plus `/api` when you host it yourself ([your API's address and a
token](/api#your-apis-address-and-a-token)). To send requests, open `/api/docs/delivery` on your
instance, its own interactive reference. The document itself is `backend/api/openapi/delivery.yaml` in the repository
(OpenAPI 3.0), for generating a client, and here to download:

<OpenAPIDownload api="delivery" />

For a retrieval pipeline, see [Integrating with a RAG pipeline](/guides/rag).
