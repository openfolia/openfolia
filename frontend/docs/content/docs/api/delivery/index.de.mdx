---
title: 'Delivery API'
description: 'Freigegebene Inhalte lesen: für Portale, Apps, Integrationen und RAG-Pipelines.'
---

Die Delivery API enthält, was jemand für einen eigenen Viewer, ein Portal oder eine Integration
braucht: die lesenden Routen über freigegebene Inhalte und nichts über Entwürfe. Das Token eines
Konsumenten gehört zu einem Dienstkonto, dessen Rolle nur `content.read` hält.

Jede Operation hat eine Seite in der Seitenleiste, mit Parametern, Antworten, Schemas,
Codebeispielen und einer Testumgebung; diese Seiten sind auf Englisch. Das Dokument selbst ist
`backend/api/openapi/delivery.yaml` im Repository (OpenAPI 3.0), etwa um einen Client zu erzeugen, und
hier zum Herunterladen:

<OpenAPIDownload api="delivery" lang="de" />

Für eine Retrieval-Pipeline siehe [Anbindung an eine RAG-Pipeline](/de/guides/rag).
