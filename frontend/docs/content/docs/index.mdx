OpenFolia is a headless documentation platform. Content is written once as small modules, then
assembled into manuals for each product variant and language. Authors work in a web editor
on drafts that go through review before they are released. Every release is served by a JSON:API
and rendered to PDF and HTML, so the same content reaches print, a portal and other systems.

Almost everything in it is content: the modules, and also the manuals, the project settings, the
page designs and the terms, all versioned in Git and changed through review. See
[Almost everything is content](/guide/getting-started/content).
