OpenFolia is a documentation platform: an editor, review and releases, and a reader portal.
Content is written once as small modules, then assembled into manuals for each product variant and
language. Authors work in a web editor on drafts that go through review before
they are released. Every release becomes accessible PDF and HTML, a [portal](/guide/portal) your
readers browse and search, and a JSON:API for other systems, so the same content reaches print,
the web and your own applications.

Almost everything in it is content: the modules, and also the manuals, the project settings, the
page designs and the terms, all versioned in Git and changed through review. See
[Almost everything is content](/guide/getting-started/content).

## Use your OpenFolia

Your OpenFolia has an address of its own: `https://<team>.openfolia.com` when it is hosted for you,
or the address your admin gives you. Open it in your browser and sign in. Programs and
agents reach the same content through its API at that address plus `/api`.

The reference is generated from the source code, so it always matches the release it belongs to:

- [API reference](/api): every route of the Delivery API and the Management API, with schemas and

  your OpenFolia.
- [Error codes](/reference/errors), [permissions](/reference/permissions) and
  [settings](/reference/settings).
- [Project configuration (`openfolia.yaml`)](/reference/project-config),
