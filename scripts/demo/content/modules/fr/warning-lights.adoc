= Témoins d'alerte
:schema-version: 1
:module-type: reference
:lang: fr
:audience: owner
:facet-product: fenna
:keywords: témoins

[#intro]
Un témoin rouge signifie : arrêtez-vous dès que possible en toute sécurité. Un témoin jaune signifie : faites contrôler le véhicule rapidement.
