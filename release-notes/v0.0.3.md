OpenFolia now runs on Arm servers, and it can be tried without installing it: a public sandbox
mode gives every visitor of a demo an OpenFolia of their own, deleted after the session. The
reader portal gets a search that answers as you type and a variant switch that says what it does.

- Images: every image is built for both amd64 and arm64, natively on each, as one multi-platform
  image. The same compose.yaml runs on an x86 server, an Arm server or an Apple silicon Mac.
- Sandbox: a public sandbox mode (CCMS_PUBLIC_SANDBOX=on) for a throwaway instance open to
  anyone: no outbound connections, no users or tokens, no uploads, caps on what can be written,
  and a banner with the time left. The sandbox image runs it with a finished demo baked in,
  ready in a few seconds.
- Demo: the sandbox launcher starts one sandbox per visitor behind a start page, with a
  proof-of-work, per-address limits and a cap, each sandbox on its own network with no route
  out. A visitor can end their sandbox from its banner; when it ends or expires, the start page
  thanks them and can offer to book a demo. deploy/compose.demo.yaml runs the launcher, its
  agent, a shared read-only demo portal and TLS on one host.
- Portal: a typeahead on the search fields shows the best passages as you type, with full
  keyboard support. The search page and the typeahead share one search.
- Portal: when a manual isn't published in every combination of its variant attributes, the
  variant switch says so before the click ("only as Electric") and, after it, which other
  setting changed. Switching between variants no longer blanks the page.
- Portal: search excerpts no longer run a glossary term into its definition.
- Editor: a revision with no changes against its base shows that, without an empty diff's view
  switch and legend.
- MCP: the editor serves the MCP server at /mcp on its own address, so an assistant connects
  to https://<your address>/mcp with the instance's MCP token. The MCP server believes a
  forwarded client address only from the proxies named in CCMS_MCP_HTTP_PROXY_ADDRESSES.
- Docs: a full MCP page (address, token, client setups, tools and resources, troubleshooting),
  and the docs now start from using an OpenFolia someone runs for you, with running it
  yourself as the second path. The API reference's server is https://{host}/api with the
  host editable, never localhost.
- German: the interface says Anleitung, the glossary term, throughout.
- Security: SECURITY.md now states which versions get security fixes: the latest release and
  main.

To upgrade from v0.0.2, follow "Upgrades" in deploy/README.md. An installation that runs the
MCP service becomes reachable at the editor's address plus /mcp, behind the same token; the
sandbox mode and the demo are separate deployments.
