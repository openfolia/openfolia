Das Leserportal läuft jetzt als Teil einer selbst betriebenen OpenFolia-Installation. Bisher
waren es statische Dateien, die Sie von Hand aus einem Klon des Repositorys gebaut haben; jetzt
kann der Stack das Portal für Sie betreiben und aktuell halten.

- Portal: ein Portal-Image und ein optionales Compose-Profil portal. Es baut das Portal mit
  einem Token, das nur lesen darf, aus der API, stellt es auf einem eigenen Port bereit
  (standardmäßig 8090), sendet die Sicherheits-Header, die ein Portal braucht, und zeigt jede neue
  Veröffentlichung nach wenigen Minuten, ohne Neustart. Schlägt ein Build fehl, bleibt der letzte
  gute online; zurückgezogene Inhalte werden entfernt.
- Portal: deploy/self-host.sh --portal richtet es in einem Schritt ein: eine Rolle und ein
  Dienstkonto, die nur lesen dürfen, für die Zielgruppe Ihrer Wahl, das Token in den Einstellungen
  des Stacks gespeichert und nie angezeigt, und die Adresse des Portals neben der des Editors.
- Dokumentation: ein eigener Abschnitt „Portal“ im Benutzerhandbuch (Überblick, Bauen und
  Vorschau, Branding, Hosting und Betrieb mit Docker Compose). Die alte Portalseite leitet dorthin
  weiter.
- Dokumentation: Die Dokumentation einer Veröffentlichung enthält diese jetzt in ihrem
  Änderungsprotokoll.

Für das Upgrade von v0.0.1 folgen Sie „Upgrades“ in deploy/README.md. Das
Portal ist optional: Ohne das Profil portal ändert sich nichts.
