# Docs inventory

Every feature a person, an operator or an integrator needs explained, and where the documentation will cover it. The user guide (#447) and the docs site (#420) are written from this list, and a line is ticked once its page exists.

- **One line per feature:** `- [ ] <feature in plain words> — <audience> — <PRs or issues> — <guide page>`.
- **Audience:** W writer, R reviewer, T translator, A admin, O operator, I integrator.
- `(generated)`: a reference the docs site generates (the API, the settings, the permissions, the shortcuts) covers it fully.
- **A change that adds or changes such a feature adds or updates its line here**, in its area's section, in the same pull request. The pull request's "Docs" section names the line (`docs/agent-rules.md`).
- **Coming** lists planned features. Move a line into its area when it ships.
